template<typename RealType>
class UE::Geometry::TMeshTangents< RealType >

TMeshTangents is a utility class that can calculate and store various types of tangent vectors for a FDynamicMesh.

Compute per-triangle tangents for the given UV Overlay. Computation is done in parallel.

参数
bOrthogonalizeif true, we orthogonalize the tangents by computing the Bitangent sign and regenerating it. Otherwise the tangents are left non-orthogonal.

const FComputeTangentsOptions & Options )

Calculate per-triangle tangent spaces based on the given per-triangle normal and UV overlays. In this mode there is no averaging of tangents across triangles. So if we have N triangles in the mesh, then 3*N tangents are generated. These tangents are optionally computed in parallel.
