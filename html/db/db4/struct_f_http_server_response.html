◆ StreamingBodyQueue

TSharedPtr<TQueue<TArray<uint8>, EQueueMode::Spsc> > FHttpServerResponse::StreamingBodyQueue

Optional: streaming body queue. When set, WriteStream will drain this queue chunk-by-chunk in addition to (after) the initial Body content. Must be an SPSC queue: one producer thread enqueues chunks, the game thread (WriteStream) dequeues. Set bStreamingBodyComplete to true after all chunks have been enqueued.
