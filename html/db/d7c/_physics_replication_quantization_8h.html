◆ CanonicalizeQuatForLog()

FQuat CanonicalizeQuatForLog ( const FQuat & Q)
inline

Canonicalize a quaternion's sign for logging and comparison. Q and the negated quaternion represent the same rotation, so two endpoints that are rotationally identical can print with all four components negated and look like a huge diff. Force W to be non negative (and use X then Y then Z as tiebreakers when W==0) so any two equal rotations print identically. The returned value is only for display. Do not feed it back into the simulation.
