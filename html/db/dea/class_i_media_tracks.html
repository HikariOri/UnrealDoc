◆ GetTrackDuration()

virtual TOptional< FTimespan > IMediaTracks::GetTrackDuration ( EMediaTrackType TrackType,
int32 TrackIndex ) const
inlinevirtual

Returns the duration of a specific track.

If a media file contains multiple tracks each track may have different duration and the overall media duration is typically reported as that from the longest track.

For some applications it may be required to know the exact track duration for processing, which is what this method returns if the media container, as well as the media player used for playback has the ability to provide it.

参数
TrackTypeThe type of track to query.
TrackIndexThe index of the track to query.
返回
The duration of the track if known.

virtual bool IMediaTracks::SelectTrack ( EMediaTrackType TrackType,
int32 TrackIndex )
pure virtual

Select the active track of the given type.

The selected track will use its currently active format. Active formats will be remembered on a per track basis. The first available format is active by default. To switch the track format, use SetTrackFormat instead.

参数
TrackTypeThe type of track to select.
TrackIndexThe index of the track to select, or INDEX_NONE to deselect.
返回
true if the track was selected, false otherwise.
