详细描述

A string prefix tree is conceptually similar to a trie. However, instead of adding a new nodes per single character, nodes encode a string prefix, and entries are built up by concatenating the path to the node. For example, if we add the entries "ABC", "AC", and "D" to the tree, we will have: <root> |- "A" | |- "B" | | |- "C" * | |- "C" * |- "D" *

Where only the nodes marked with * are leaf nodes. An entry is considered to be in the list only if it is a leaf node. This tree structure allows for long strings that may have long similar sections to be searched far faster than storing them in eg. a set.
