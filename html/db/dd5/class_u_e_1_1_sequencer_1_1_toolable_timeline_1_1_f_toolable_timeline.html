template<typename TToolType, typename = TEnableIf<TIsDerivedFrom<TToolType, IToolableTimelineToolFactory>::IsDerived>::Type>
bool UE::Sequencer::ToolableTimeline::FToolableTimeline::AddToolFactory ( )
inline

Adds a new tool factory of the specified type to the timeline if it doesn't already exist.

This method checks for the existence of a tool factory of the specified type TToolType. If not already present, it creates a new factory instance, adds it to the tool factories list, and sorts the list based on priority. The operation returns a flag indicating whether the addition was successful.

模板参数
TToolTypeThe type of the tool factory to add. Must derive from IToolableTimelineToolFactory.
返回
True if the tool factory was successfully added; false if a tool factory of the specified type already exists or the addition fails.

protected

Retrieves all unique key times for every cached channel associated with the timeline.

This method iterates through all cached channels, collects key times from valid key areas, ensures uniqueness, and sorts the key times. The result includes all key times from available channels.

返回
An array of sorted, unique frame numbers representing all key times within the timeline's channels.
