详细描述

Base class for all editor modes.

Modes can be switched. Different modes may have different widgets / editing functionality / layouts. Modes can also be compatible, so multiple modes can concurrently affect a single asset editor. Modes defined in separate modules, say from a plugin, can modify existing asset editors in a different module.
