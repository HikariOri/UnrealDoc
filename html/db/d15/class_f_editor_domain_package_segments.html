详细描述

Helper class for archive classes that server either an EditorDomain version of a package or the WorkspaceDomain version. Starts with a request to the Cache to load the metadata for an EditorDomainPackage. If the request fails, goes dormant and the owner class falls back to workspace domain. If the request succeeds, it makes all Attachments from the CacheRecord available as individually fetched segments.
