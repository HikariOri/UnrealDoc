16 // An aabb tree meant for infrequently moving / updated objects.
17 // Building this tree is more computationally expensive than its dynamic counterpart, but should produce a better quality tree.
18 // When Insert/Updating/Removing objects, there are two primary APIs:
19 // 1. Deferred: does the minimal work to make sure the tree will be correct the next build and won't return removed objects.
20 // 2. Incremental (TODO): does incremental changes to the tree (similar to the dynamic tree) to ensure everything is up-to-date for all queries.
21 // In general, incremental changes are faster to perform but will result in a slightly worse quality tree. Thus, it is recommended to perform periodic full rebuilds.
