详细描述

This class is utilized to help layout math expression nodes by traversing the expression tree and cataloging each expression node's depth. From the tree's depth we can determine the width of the the graph (an where to place each K2 node):

_ | [_]—[_] | / height [_]– [_]–[_]—[_] | \ / |_ [_]—[_] 

  ^-------depth/width-------^
