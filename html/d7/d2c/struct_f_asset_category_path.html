详细描述

The asset category path is how we know how to build menus around assets.
For example, Basic is generally the ones we expose at the top level, where as everything else is a category with a pull out menu, and the subcategory would be where it gets placed in a submenu inside of there.

Currently, the system supports chaining menus and as the last entry you can have a custom section.
You can't have a menu inside a section so the section should be the last in case you want one.

Constructs from a root FAssetCategoryPath followed by any number of FCategoryPath.
By default, every FText given is treated like a menu.
If the last entry is a section you should still explicitly add it like so:
FAssetCategoryPath(FAssetCategoryPath or (FText), FCategoryPath or (FText)..., FCategoryPath(FText, ECategoryMenuType::Section))
