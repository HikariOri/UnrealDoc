131 uint32 ReferenceCount;
132 // Stored as int32 because ICU's UDataMemory::length (udatamem.h) is int32_t — the value written
133 // here is ultimately assigned to pData->length in uprv_mapFileFromCallback, so widening to int64
134 // would not eliminate the narrowing; it would just move it into ICU's own internals. int32 also
135 // avoids the 4-byte alignment padding that int64 would introduce after ReferenceCount, increasing
136 // every cache entry by 8 bytes. No ICU data file approaches 2GB — the largest full locale set
137 // is order of tens of MB.
