详细描述

Collects the memory version of a saved package, compares it with an existing package on disk, and reports callstack for the Serialize call at each offset where they differ.

It works by saving a package twice. The first pass collects the serialization offsets without the stack traces and creates a FDiffMap, and records sizes necessary to remap offsets during Serialize to the final offset in the package on disk. In the second pass, the diff map is read during each call to Serialize to decide whether we need to collect the stack trace for that call.
