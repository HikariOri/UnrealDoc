◆ GAdaptiveVirtualTextureMaxAllocationsOverride

int32 GAdaptiveVirtualTextureMaxAllocationsOverride
extern

Defined by the adaptive virtual texture implementation. Replaces its per frame allocation budget when greater than zero.

Replaces the r.VT.AVT.MaxAllocPerFrame budget for the current update when greater than zero. Set by the virtual texture system for updates that run without throttling.
