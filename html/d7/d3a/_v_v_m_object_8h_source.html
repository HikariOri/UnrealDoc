65 /*
66 * Mutable variables store their data as a `VRestValue`.
67 * It's not an array of `VValue`s because you can potentially load a class member before actually defining it. i.e.
68 *
69 * ```
70 * c := class {x:int}
71 * C := c{}
72 * Foo(C.X) # allocates a placeholder
73 * C.X := 1 # This is the first time `c.X` actually gets defined.
74 * ```
75 *
76 * This stores the actual data for individual fields. Some constants and procedures are stored in the shape, not the
77 * object (since then there's no need to do an unnecessary index lookup).
78 *
79 * The mapping of offsets to each field are stored in the emergent type's "shape". The reason why the object
80 * doesn't just store the mapping of fields to data itself is that it will eventually help when we implement inline
81 * caches for retrieving fields on objects. It also helps reduce memory usage because multiple objects can share
82 * the same hash table that describes their layouts.
83 */
84 inline void* GetData(const VCppClassInfo& CppClassInfo) const;
85 inline VRestValue* GetFieldData(const VCppClassInfo& CppClassInfo) const;
86};
