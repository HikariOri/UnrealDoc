◆ EnableVREditor()

virtual void IVREditorModule::EnableVREditor ( const bool bEnable,
const bool bForceWithoutHMD = false )
pure virtual

Enables or disables editor VR features. Calling this to active VR will turn on the HMD and setup the editor UI for VR interaction.

参数
bEnableTrue to enable VR, or false to turn it off
bForceWithoutHMDIf set to true, will enter VR mode without switching to HMD/stereo. This can be useful for testing.
