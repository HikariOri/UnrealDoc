详细描述

These are options for the LastResortPropertyNetSerializer that are user controllable by passing an instance to a registration macro, for example UE_NET_IMPLEMENT_NAMED_STRUCT_LASTRESORT_NETSERIALIZER_AND_REGISTRY_DELEGATES(MyStruct, {.MaxQuantizedSizeBits = 32767})

◆ bExcludeFromDefaultStateHash

bool UE::Net::FLastResortPropertyNetSerializerUserOptions::bExcludeFromDefaultStateHash = false

Whether to exclude the serialization from being part of a replication state's default state hash. This should be done only if the property may differ on the sending and receiving side.

CreateAndRegisterReplicationFragmentFunc UE::Net::FLastResortPropertyNetSerializerUserOptions::CreateAndRegisterReplicationFragmentFunction = nullptr

◆ MaxQuantizedSizeBits

uint32 UE::Net::FLastResortPropertyNetSerializerUserOptions::MaxQuantizedSizeBits = 0

How large the quantized state may be in bits. Only needed to be set if the requirements are very high. Leave as 0 to use whatever the default is (65535).
