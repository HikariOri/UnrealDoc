◆ DoReadbackIfNeeded()

bool FSkinWeightProfilesData::DoReadbackIfNeeded ( const FSkinWeightProfileStack & InProfileStack)
返回
Returns true if GPU Readback data is ready and buffer has been initialized. Otherwise, returns false and ticks the GPU Readback pump. If true, it is safe to update the skin weight override buffer for given Skeletal Mesh LOD this Skin Weight Data is associated with.

◆ ShouldEnqueueGPUReadback()

bool FSkinWeightProfilesData::ShouldEnqueueGPUReadback ( ) const
返回
True if a call to EnqueueGPUReadback would actually issue an RT command that produces a GPU readback (i.e. base buffer / weight data is available, and CPU data is not already a usable substitute). Use this to decide whether it is worth registering stream-out protection or otherwise paying the readback cost.
