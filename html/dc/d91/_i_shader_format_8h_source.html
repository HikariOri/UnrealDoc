179 /*
180 * Implement to output debug info for a single compile job.
181 * This will be called for all jobs (including those found in the job cache) but only if debug info is enabled for the job.
182 * Note that any debug info output in CompilePreprocessedShader will only be done for the job that actually executes the
183 * compile step, as such any debug outputs that are desirable for all jobs should be written by this function.
184 * A BaseShaderFormat implementation is provided in ShaderCompilerCommon which dumps preprocessed and stripped USFs along
185 * with the hash of the shader code in an OutputHash.txt file; if no additional custom debug output is required the shader
186 * format can inherit from FBaseShaderFormat instead of IShaderFormat.
187 */

198 * which require secondary compilation, even if inheriting from FBaseShaderFormat.
