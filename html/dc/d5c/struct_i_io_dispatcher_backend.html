详细描述

I/O dispatcher backend interface.

The following methods are called from the I/O dispatcher thread:

  • ResolveIoRequests
  • CancelIoRequest
  • UpdatePriorityForIoRequest
  • GetCompletedRequests

All other methods can be called from any thread.
