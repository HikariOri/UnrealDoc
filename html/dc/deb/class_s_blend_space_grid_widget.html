◆ EDragState

enum class SBlendSpaceGridWidget::EDragState
strongprotected

Represents the different states of a drag operation

枚举值
PreDrag 

The user has clicked a mouse button, but hasn't moved more then the drag threshold.

DragSample 

The user is dragging the selected sample.

Preview 

The user is setting the preview value

DragDrop 

The user is dropping a new sample onto the grid

DragDropOverride 

The user is dropping a new animation to an existing sample on the grid

InvalidDragDrop 

The user is dropping an invalid animation sequence onto the grid

None 

There is no active drag operation.

Called during drag and drop when the drag enters a widget.

Enter/Leave events in slate are meant as lightweight notifications. So we do not want to capture mouse or set focus in response to these. However, OnDragEnter must also support external APIs (e.g. OLE Drag/Drop) Those require that we let them know whether we can handle the content being dragged OnDragEnter.

The concession is to return a can_handled/cannot_handle boolean rather than a full FReply.
