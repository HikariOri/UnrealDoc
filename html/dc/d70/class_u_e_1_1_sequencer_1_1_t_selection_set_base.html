详细描述

template<typename MixinType, typename KeyType>
class UE::Sequencer::TSelectionSetBase< MixinType, KeyType >

Typed selection set for keeping track of an externally provided key type KeyType is what is stored within the selection set (ie, an FObjectKey, TWeakPtr or int32) MixinType is the type of the derived class. This allows for compile-time injection of OnSelect/OnDeselect behavior without needing virtual function calls: 

 bool OnSelectItem(const KeyType&){ return true; }
 void OnDeselectItem(const KeyType&){}

Example implementation: class FMySelection : TSelectionSetBase<FMySelection, uint32> { public: // Both these functions are optional: bool OnSelectItem(uint32 In){ return In != 0; } void OnDeselectItem(uint32){} };

Iteration is supported for all types (weak ptrs are skipped and iterated as shared pointers): 

class FMySelection : TSelectionSetBase<FMySelection, FWeakViewModelPtr>{};
FMySelection& Selection = ...;
for (FViewModelPtr ViewModel : Selection)
{
    //...;
}

// Filtered iteration is also supported for TWeakViewModelPtr<> types:
for (TViewModelPtr<IOutlinerExtension> Outliner : Selection.Filter<IOutlinerExtension>())
{
    // Only viewmodels that implement the IOutlinerExtension will be iterated
}
