This function checks whether a node passes the filter defined by IsClassAllowed/IsUnloadedClassAllowed.

参数
InInitOptionsThe Class Viewer/Picker options.
NodeThe Node to check.
bCheckTextFilterWhether to check the TextFilter. Disabling it could be useful e.g., to verify that the parent class of a IsNodeAllowed() object is also valid (regardless of the TextFilter, which will likely fail to pass).
