详细描述

Parameters for building a "Bake To Control Rig" menu section. All fields are Control Rig-agnostic so that the AnimMixer editor has no CR dependency.

TFunction<UMovieSceneTrack*(UMovieScene*, TSubclassOf<UMovieSceneTrack>)> FAnimMixerBakeMenuParams::ChildTrackFactory

Creates a child track inside the mixer at the desired location. The provider calls this with the UClass of the track to create (e.g. UMovieSceneControlRigParameterTrack). Returns the created track, or nullptr on failure.

TDelegate<bool(UAnimSequence*, UAnimSeqExportOption*, USkeletalMeshComponent*)> FAnimMixerBakeMenuParams::PopulateAnimSequence

Delegate the provider calls to populate a temporary UAnimSequence with animation data. The caller captures mixer-specific context (track, filter, etc.) in this delegate. Return true on success, false to abort the bake.
