16/*
17 * Utility to pull payloads in batches from many threads at once which can be much faster than pulling from a single thread
18 * in a single batch. The provided callback will be invoked each time that a request is completed.
19 * Every 30 seconds an update will be printed to the log showing how many payloads have been processed so that the user does
20 * not think that the process has stalled.
21 *
22 * @param PayloadIds The payloads that should be pulled
23 * @param BatchSize The max number of payload ids that should be in each batch
24 * @param ProgressString An optional string to be printed as part of the status shown every 30 seconds, can be nullptr.
25 * @param Callback Called on every request once it has been processed.
26 *
27 * @ return True if all requests succeeded, false if there were failures.
28 */
29bool PullPayloadsThreaded(TConstArrayView<FIoHash> PayloadIds, int32 BatchSize, const TCHAR* ProgressString, TUniqueFunction<void(const UE::Virtualization::FPullRequest& Response)>&& Callback);
