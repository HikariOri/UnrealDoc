Compute open boundary loops of a mesh.

参数
MeshThe mesh to compute boundaries of
OutPackedBoundaryVertLoopsThe boundary loops packed as [NumVertsInLoop0, LoopVID0, LoopVID1, ... LoopVIDN, NumVertsInLoop1, etc]
OptionalOutPackedBoundaryTriLoopsIf non-null, the boundary loops packed as [NumTrisInLoop0, LoopTri0, LoopTri1, ... LoopTriN, NumTrisInLoop1, etc]. Tris are ordered s.t. LoopTri0 has boundary edge (LoopVID0, LoopVID1).
VertexWeldFnA function taking a vertex ID to a 'welded' ID (which must always be one of the IDs of the vertices that was welded, i.e. if vertex 3 and 5 are welded, the weld ID is either 3 or 5)
FilterOptionsOptions filtering loops from inclusion in the output, e.g. if they are too small
返回
Number of boundary loops found

TFunctionRef< void(const FIndex3i &Tri, int32 SourceTID)> AddTriFn )

Add a strip of offset geometry along mesh boundary loops (as computed by ComputeBoundaryLoops above).

Walks each boundary edge and, for each of its two endpoints, calls GetOrCreateOffsetVertFn to get boundary/offset vertex pairs, then calls AddTriFn twice to add a two-triangle quad extending from the boundary edge.

参数
MeshThe mesh to extend with offset geometry
PackedBoundaryVertLoopsThe boundary loops packed as [NumVertsInLoop0, LoopVID0, LoopVID1, ... LoopVIDN, NumVertsInLoop1, etc]
PackedBoundaryTriLoopsThe boundary loops packed as [NumTrisInLoop0, LoopTri0, LoopTri1, ... LoopTriN, NumTrisInLoop1, etc]. Tris are ordered s.t. LoopTri0 has boundary edge (LoopVID0, LoopVID1).
GetOrCreateOffsetVertFnCalled per boundary-edge-endpoint, returning the boundary vertex and its offset pair. Should add the offset vertices (or find already-added ones) as needed.
AddTriFnFunction to add a new triangle to the mesh; Called per emitted skirt triangle with the source TID of the driving boundary edge.
