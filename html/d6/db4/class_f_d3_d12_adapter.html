Controls the heuristics used by Windows Video Memory Manager to demote resources from GPU physical memory when it is overcommitted or fragmented. The D3D12 RHI performs access tracking and manual residency management, however it is still possible to overcommit under some conditions on low-VRAM GPUs. Render targets, depth buffers and UAVs are assigned high residency priority by default. To differentiate between high priority resources, the size is packed into low 16 bits of the priority value (in units of 10MB). If ResourceSize parameter is specified, the final priority value will be packed in a mannner consistent with the default priority assignment. Current priority value is stored in the Pageable private data. The size bits will be preserved if priority changes but the size is not provided in subsequent calls to this function. See https://learn.microsoft.com/en-us/windows/win32/direct3d12/residency.
