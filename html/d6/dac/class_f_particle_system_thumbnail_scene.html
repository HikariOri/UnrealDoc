Gets parameters to create a view matrix to be used by CreateView(). Implemented in children classes.

参数
InFOVDegreesThe FOV used to display the thumbnail. Often used to calculate the output parameters.
OutOriginThe origin of the orbit view. Typically the center of the bounds of the target object.
OutOrbitPitchThe pitch of the orbit cam around the object.
OutOrbitYawThe yaw of the orbit cam around the object.
OutOrbitZoomThe camera distance from the object.
