BuildPatchServices::FCloudEnumeration::FCloudEnumeration ( const FString & CloudDirectory,
const FDateTime & ManifestAgeThreshold,
const TFunction< bool(const IBuildManifest &)> & InPredicate,
const EFeatureLevel & InOutputFeatureLevel,
FStatsCollector * StatsCollector )

Creates an instance of FCloudEnumeration for managing cloud uploaded manifests and chunks.

参数
CloudDirectoryThe cloud root directory.
ManifestAgeThresholdThe threshold age for manifest files; files older than this will be ignored.
PredicateA callable that takes a const reference to an IBuildManifest and returns true to include the manifest, or false to ignore it.
OutputFeatureLevelThe desired feature level for enumerated output.
StatsCollectorA pointer to the statistics collector for recording related data.
