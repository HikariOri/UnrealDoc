详细描述

The implementation of ActiveMountsLoading. This implementation class is created only when the feature is enabled in the current process. It holds data about how to reload each mountpoint and manages their state in an unload/reload state machine.

Called by FActiveMountsLoaderWrapper::UnregisterAssetProvider. Signals the AssetProvider's load thread to shutdown if it exists and reports the EventRefs that must be waited on for it to terminate. Followed by a call to FinishUnregisterAssetProvider after waiting. Returns false if the AssetProvider does not exist; FinishUnregisterAssetProvider should not be called in that case.
