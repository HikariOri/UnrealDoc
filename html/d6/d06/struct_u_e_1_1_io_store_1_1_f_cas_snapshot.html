◆ AppendAndResetJournal()

TResult< int64 > UE::IoStore::FCasSnapshot::AppendAndResetJournal ( const FString & SnapshotFile,
const FString & JournalFile )
static

Append the journal file to the snapshot and reset the journal file.

参数
SnapshotFileThe snapshot file to appened the journal to. May not exist yet.
JournalFileThe journal file to append to the snapshot, and then reset.

Note: If this operation fails, it will leave behind temporary files, call TempFilesExist() check for them. There is no provided method to cleanup temporary files. If they are discovered, the cache is in an inconsistent state and should be reset.
