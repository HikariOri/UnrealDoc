40// This trait defines how different native arguments map to property types.
41//
42// Using this trait isn't sufficient to fully create an instance of a property class given a native type, as some types
43// will require inner setup too, e.g. a property representing TOptional<int32> requires creating an FOptionalProperty
44// with an inner FIntProperty, or a property representing FVector will need an inner UStruct*. Use a helper function
45// like CreatePropertyForNativeType<T>() for a complete property.
46//
47// There is overlap with TCPPTypeToPropertyType in Editor/Kismet/Internal/Reflections/FunctionUtilsPrivate.h, so
48// these could be unified in future.
49template <typename T>
50struct TNativeTypeToPropertyType
51{
52};
