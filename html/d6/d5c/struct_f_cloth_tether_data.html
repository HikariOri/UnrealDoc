详细描述

Long range attachment tether pathfinding based on Dijkstra's algorithm. For more information about the long range attachment, see: https://matthias-research.github.io/pages/publications/sca2012cloth.pdf

◆ KinematicDistanceThreshold

float FClothTetherData::KinematicDistanceThreshold = 0.1f
staticconstexpr

Particles whose MaxDistance / TetherEnds mask is strictly less than this are treated as kinematic for tether sorting. Authoritative source for the legacy "barely allowed to move" cutoff — referenced by the converter and consumed throughout the cloth simulation pipeline so the same threshold is applied to legacy assets at convert time and to runtime tether generation.
