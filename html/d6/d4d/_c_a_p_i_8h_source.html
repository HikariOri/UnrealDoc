30 // The C API exists for a few reasons:
31 //
32 // - It makes linking easy. AutoRTFM has to deal with a weird kind of linking
33 // where the compiler directly emits calls to functions with a given name.
34 // It's easiest to do that in llvm if the functions have C linkage and C ABI.
35 // - It makes testing easy. Even seemingly simple C++ code introduces pitfalls
36 // for AutoRTFM. So very focused tests work best when written in C.
37 // - It makes compiler optimizations much easier as there is no mangling to
38 // consider when looking for functions in the runtime we can optimize.
39 //
40 // We use snake_case for C API surface area to make it easy to distinguish.
41 //
42 // The C API should not be used directly - it is here purely as an
43 // implementation detail.

166 // Custom abort handler for writes that that were added with the
167 // autortfm_write_custom_rollback flag. It is the responsibility of this
168 // function to perform the rollback (copy of Size bytes from Value to
169 // Address).
170 // RollbackWrite may contain multiple writes condensed into a single
171 // contigious block of memory, and the writes may be split into multiple
172 // calls with no defined size or alignment granularity.
173 // Calls are ordered starting with the most recently recorded writes.
174 // Address / Value pointers are ordered starting with the least recently
175 // recorded writes.
176 // Split writes are guaranteed to be "completed" with the next immediate
177 // call(s).
178 void (*RollbackWrite)(void* Address, const void* Value, size_t Size, autortfm_write_flags Flags);
