详细描述

Custom lock class that can prioritize waiters upon request. This is used to allow threads with critical requests to request that the gatherer thread pause its work and allow the higher pri threads to jump in. Note that for this to work correctly it must be used with the associated TPriorityScopeLock types (TScopeLockWithPriority and FRWScopeLockWithPriority)
