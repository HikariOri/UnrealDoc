详细描述

The manager to handle renaming assets. This manager attempts to fix up references in memory if possible and only leaves UObjectRedirectors when needed. Redirectors are left unless ALL of the following are true about the asset 1) The asset has not yet been checked into source control. This does not apply when source control is disabled. 2) The user is able and willing to check out all uasset files that directly reference the asset from source control. The files must be at head revision and not checked out by another user. This rule does not apply when source control is disabled. 3) No maps reference the asset directly. 4) All uasset files that directly reference the asset are writable on disk.
