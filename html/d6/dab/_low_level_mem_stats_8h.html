◆ LLM_SCOPE_DYNAMIC_STAT_OBJECTPATH

#define LLM_SCOPE_DYNAMIC_STAT_OBJECTPATH ( ...)

LLM optionally-use-Stats scope macros. These are active even if STATS is defined out; they still create LLM tag scopes. If STATS is defined in, they also create a STAT matching the tag (if their tagset is active in LLM). They are noops if LLM is defined out. When defined in, they are inactive unless toggled on by LLM command line options.
