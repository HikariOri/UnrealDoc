详细描述

Helper class for limiting download rate using an implementation of the token bucket algorithm.

One 'token' in this context is a byte that we can schedule for download. On tick, we increase the number of available tokens according to the configured download rate limit. When we want to schedule a chunk for download we must confirm that enough tokens are available and consume them appropriately. The result is that the average download rate cannot exceed the configured limit, although short bursts of higher rates are likely.
