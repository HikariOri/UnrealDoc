详细描述

OfflineShaderCompiler's compilation command line options. Each OfflineShaderCompiler should specify its own FOfflineShaderCompilerOptions. If one option is not supported by this OfflineShaderCompiler, leave it empty. Frequency (VS/PS/etc.) here is called as stage sometime, too.
