19// COMMANDLET TO CONVERT DATALAYERS TO DATA LAYERS ASSET AND DATA LAYERS INSTANCES WITHIN A GIVEN WORLD.
20//
21// All data layers will be converted to data layer instances and data layer assets.The commandlet will create the data layer assets at the specified destination folder.
22// All actors will now be referencing data layer assets.
23//
24// RUNNNING THE COMMANDLET:
25// [Project] -run=DataLayerToAssetCommandlet [LevelName] -DestinationFolder=[Folder]
26//
27// -DestinationFolder : Specifies the folder where the Data Layer Assets will be created
28//
29// Optional Args :
30//
31// -NoSave : Will run the commandlet, report information, but will not save.
32// -IgnoreActorLoadingErrors: Will ignore if an actor failed to load.By default the commandlet will abort upon those errors.
33// -Verbose: Adds extra logging information.
34//
35//
36// If the Commandlet fails it will report an error which will need to be addressed.
37// Once the commandlet finishes successfully, all data layers will be saved and actors will be updated.
38//
39// PROJECT SPECIFIC CONVERSION:
40// Some projects might have added additional references to data layers. Those projects can subclass UDataLayerToAssetCommandlet and override 2 functions
41// virtual bool PerformAdditionalActorConversions(...) : Called on every actor when they are converted.
42// virtual bool PerformProjectSpecificConversions(...) : Called before wrapping up the commandlet.
43//
44// Both functions receive the CommandletContext in parameter.
45// UDataLayerConversionInfo* UDataLayerToAssetCommandletContext::GetDataLayerConversionInfo(...) can be used to retrieve the conversion information for a specific data layer.
46// the UDataLayerConversionInfo reference the UDeprecatedDataLayerInstance to convert, the newly created UDataLayerAsset and the newly created UDataLayerInstanceWithAsset.
47//
