◆ ESaveStorageResult

enum class UE::EditorDomain::ESaveStorageResult
strong

A result code indicating whether a EditorDomain package could be saved into the editor domain, and if not why not EditorDomain records in DDC have a Valid flag in their metadata. If the Valid flag is invalid, the record does not store a EditorDomain package and it instead has a StorageResult in the metadata explaining why it failed.

Valid 
UnexpectedClass
