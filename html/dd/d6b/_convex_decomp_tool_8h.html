◆ DEFAULT_HACD_VOXEL_RESOLUTION

#define DEFAULT_HACD_VOXEL_RESOLUTION   100000

This pre-processor define specifies the default voxel resolution when performing V-HACD. The default value is one hundred thousands voxels. The valid range is between 10,000 to 16 million. Generally speaking 100,000 is more than enough precision for any mesh your might care to process.
