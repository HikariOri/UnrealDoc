◆ RegisterSurfaceForTouch()

APPLICATIONCORE_API FInputDeviceId FAndroidInputInterface::RegisterSurfaceForTouch ( const TSharedRef< FAndroidWindow > & Window)
static

Register an Android Surface so that touches associated with it can be processed properly by QueueTouchInput. This is necessary when allocating any Surfaces other than the primary activity one that the engine owns, because Android reports touch device ID based on the physical hardware, but tracks finger indices uniquely per Surface. Unreal expects finger indices to be unique per device.

Caller is responsible for mapping the returned device to an FPlatformUserId, and for forwarding touch events to QueueTouchInput.
