39 // FLogTemplate is 8 bytes plus the encoded ops.
40 // There are 2 ops for each field. There is 1 op for each contiguous region of literal text.
41 // There is 1 op for each escaped character. There is 1 op to mark the end.
42 // Most ops encode as 1 byte. A format string that has 12 fields with text surrounding each
