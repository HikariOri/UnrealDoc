◆ TryExpedite() [1/2]

bool LowLevelTasks::FTask::TryExpedite ( )
inline

Try to expedite the task, if possible it will run immediately but it will not set the completed state until the scheduler has executed it, because the scheduler still holds a reference. To check for completion in the context of expediting use WasExpedited. The TaskHandle cannot be reused until IsCompleted returns true.

参数
Continuationoptional Continuation that needs to be executed or scheduled by the caller (can only be non null if the operation returned true)
