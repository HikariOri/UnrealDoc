55// The sound asset compression type to use for assets using the compression type "project defined".
56UENUM()
57enum class EDefaultAudioCompressionType : uint8
58{
59 // Perceptual-based codec which supports all features across all platforms.
60 BinkAudio,
61
62 // Will encode the asset using ADPCM, a time-domain codec that has fixed-sized quality and about ~4x compression ratio, but is relatively cheap to decode.
63 ADPCM,
64
65 // Uncompressed audio. Large memory usage (streamed chunks contain less audio per chunk) but extremely cheap to decode and supports all features.
66 PCM,
67
68 // Opus is a highly versatile audio codec. It is primarily designed for interactive speech and music transmission over the Internet, but is also applicable to storage and streaming applications.
69 Opus,
70
71 // Encodes the asset to a platform specific format and will be different depending on the platform. It does not currently support seeking.
72 PlatformSpecific,
73
74 // As BinkAudio, except better quality. Comparable CPU usage on newer platforms, higher CPU on older platforms.
75 RADAudio UMETA(DisplayName = "RAD Audio")
76};
