84// Callback functions for custom macros. Custom macros return their own substitution text, which is then further preprocessed.
85// The substitution text must include 15 bytes of padding past the null terminator, as the preprocessor uses SSE reads which may
86// read past the null terminator. The text passed to the callback includes the macro identifier and its arguments, with backslashes
87// removed. A function is called when entering the macro, and again when complete, allowing stateful logic based on whether
88// parsing is inside a certain custom macro. Any custom macro will automatically be disabled inside itself, with the idea that
89// this allows a singleton buffer for the substitution text, as there's no concern about nested calls. If text is dynamically
90// allocated, the caller is responsible for freeing it. It's also valid to return the original text passed in as the substitution
91// text, if you just want to set some state inside the context, and not actually change the macro text -- since the macro is
92// disabled, it will then be echoed as non-macro text.
93typedef const char* (*custommacro_begin_callback_func)(const char* original_text, void* custom_context);
94typedef void (*custommacro_end_callback_func)(const char* original_text, void* custom_context, const char* substitution_text);
