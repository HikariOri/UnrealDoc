◆ ParseBoolParamOrValue()

void ParseBoolParamOrValue ( const TCHAR * CommandLine,
const TCHAR * ParamNameNoDashOrEquals,
bool & bInOutValue )

Parses commandline for -Param or -Param=<1|0|true|false|on|off>. If -Param=<CoercableToBoolValue> is found, bInOutValue is set to the value. Else If -Param is found, bInOutValue is set to true. If multiple occurrences of -Param= are found, the first value is used. If neither -Param nor -Param= is found, bInOutValue is unchanged.
