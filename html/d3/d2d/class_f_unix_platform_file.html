◆ OpenMappedEx()

FOpenMappedResult FUnixPlatformFile::OpenMappedEx ( const TCHAR * Filename,
EOpenReadFlags OpenOptions = EOpenReadFlags::None,
int64 MaximumSize = 0 )
overridevirtual

Open a file for async reading. This call does hit the disk; it is synchronous open.

参数
FilenameFile to be mapped. This doesn't actually map anything, just opens the file.
OpenOptionsAllows specifying map to be writable via AllowWrite or be ReadOnly by default.
返回
Close the file by deleting the handle. A non-null return value does mean the file exists. Null can be returned for many reasons even if the file exists. Perhaps this platform does not support mapped files, or this file is compressed in a pak file. Generally you attempt to open mapped, and if that fails, then use other file operations instead. The exact file open behavior may vary per-platform when using AllowWrite. Prefer OpenMappedEx2 which has more consistent behavior across all supported platforms. OpenMappedEx is not currently deprecated so as not to change any platform specific behavior that may be implicitly relied upon.
