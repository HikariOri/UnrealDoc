详细描述

Represents a drag operation in a timeline, providing tools for managing and processing interactions such as dragging, accumulating deltas, and adjusting view ranges. This class facilitates user input handling during interactive operations on timeline widgets.

参数

◆ ComputePanSecondsFromVirtualPointerOverflow()

double UE::Sequencer::ToolableTimeline::FToolableTimelineDragOperation::ComputePanSecondsFromVirtualPointerOverflow ( ) const

Computes the pan amount in seconds, derived from the virtual pointer's overflow beyond the boundaries of the local view during a drag operation. The result indicates how far the pointer has moved beyond the defined timeline boundaries, where positive values represent overflow to the right and negative values represent overflow to the left.

返回
The computed pan amount in seconds resulting from the virtual pointer's overflow.
