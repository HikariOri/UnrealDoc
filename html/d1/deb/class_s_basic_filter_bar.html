template<typename FilterType>
class SBasicFilterBar< FilterType >

A Basic Filter Bar widget, which can be used to filter items of type [FilterType] given a list of custom filters

参见
SFilterBar in EditorWidgets if you want a Filter Bar that includes Asset Type Filters NOTE: The filter functions create copies, so you want to use a reference or pointer as the template type when possible Sample Usage: SAssignNew(MyFilterBar, SBasicFilterBar<FText&>) .OnFilterChanged() // A delegate for when the list of filters changes .CustomFilters() // An array of filters available to this FilterBar (
FGenericFilter to create simple delegate based filters)

Use the GetAllActiveFilters() function to get the FilterCollection of Active Filters in this FilterBar, that can be used to filter your items Use MakeAddFilterButton() to make the button that summons the dropdown showing all the filters
