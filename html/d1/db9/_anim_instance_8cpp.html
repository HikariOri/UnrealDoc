◆ EAnimNotifyDispatchPolicy

enum class EAnimNotifyDispatchPolicy : int32
strong

Used to determine notify dispatch behaviour when sources (montage, anim graph) may tick at different times within a frame.

枚举值
AllSources 

Previous behavior - update active notify buffers and dispatch from any source, even if that source hasn't updated before the dispatch request.

UpdatedSourcesOnly 

Only dispatch from sources that HAVE updated before the dispatch request.

Anim graph notifies/states are not triggered/ticked if the anim graph hasn't updated yet this tick. Active notify states from skipped sources remain valid (useful in MoveAutonomous / multi-tick scenarios).
