详细描述

Class responsible for tracking selections of keys. Only one type of point selection is supported at a time (key, arrive tangent, or leave tangent)

void FCurveEditorSelection::Replace ( const TMap< FCurveModelID, FKeyHandleSet > & InCurveToSelectedKeys)

Replaces the current key selection in one batched update using prebuilt per-curve key-handle sets. Curves that are invalid or read-only are skipped using the same validation rules as Add(...).

参数
InCurveToSelectedKeysMap of curve IDs to the exact selected keys to apply for each curve.

◆ Replace() [2/2]

void FCurveEditorSelection::Replace ( const TMap< FCurveModelID, TArray< FKeyHandle > > & InCurveToSelectedKeys,
const ECurvePointType InPointType )

Replaces the current key selection in one batched update using raw per-curve key-handle arrays. Curves that are invalid or read-only are skipped using the same validation rules as Add(...). All keys supplied for a given curve are associated with InPointType.

参数
InCurveToSelectedKeysMap of curve IDs to the selected key handles to apply for each curve.
InPointTypePoint type to assign to every supplied key handle.
