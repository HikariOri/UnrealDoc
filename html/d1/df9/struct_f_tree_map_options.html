◆ NameFont

FSlateFontInfo FTreeMapOptions::NameFont

Font to use for titles. This is needed so that we can calculate the amount of padding space needed. This font will be used for text titles at the root-most level of the tree. Nested levels get smaller fonts. This also affects the amount of space reserved for the title area at the top of each node.
