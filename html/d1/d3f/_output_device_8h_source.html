34/*-----------------------------------------------------------------------------
35Colorized text.
36
37To use colored text from a commandlet, you use the SET_WARN_COLOR macro with
38one of the following standard colors. Then use CLEAR_WARN_COLOR to return
39to default.
40
41To use the standard colors, you simply do this:
42SET_WARN_COLOR(COLOR_YELLOW);
43
44You can specify a background color by appending it to the foreground:
45SET_WARN_COLOR, COLOR_YELLOW COLOR_DARK_RED);
46
47This will have bright yellow text on a dark red background.
48
49Or you can make your own in the format:
50
51ForegroundRed | ForegroundGreen | ForegroundBlue | ForegroundBright | BackgroundRed | BackgroundGreen | BackgroundBlue | BackgroundBright
52where each value is either 0 or 1 (can leave off trailing 0's), so
53blue on bright yellow is "00101101" and red on black is "1"
54
55An empty string reverts to the normal gray on black.
56-----------------------------------------------------------------------------*/
