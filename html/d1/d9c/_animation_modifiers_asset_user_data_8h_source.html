57 // Animation modifiers APPLIED on the owning animation sequence
58 //
59 // - Key = Modifier in AnimationModifierInstances of owning animation sequence or skeleton
60 // - Value = Modifier instance applied
61 //
62 // Applied modifier instances stores (Properties, RevisionGuid, ...) at Apply Time
63 // Which are not visible or editable from user interface
64 //
65 // In contrast, modifiers in AnimationModifierInstances
66 // are objects displayed at the Animation Data Modifier window
67 // Where Properties are displayed for user editing anytime
68 //
69 // Note, Modifier on Skeleton (MoS) applied instances are stored on each
70 // animation sequence's asset user data, instead of the skeleton's
71 // this design is important to enable applied modifiers can be reverted for each sequence
72 // also ensure applying MoS (when [re]importing animation) will not affect the skeleton asset
73 //
74 // The only time MoS stores an applied instance here is upgrading from previous version
75 // The "UAnimationModifier::PreviouslyAppliedModifier_DEPRECATED" data will be migrated here
76 // To support proper revert for them
77 // For more compatibility handling, check UAnimationModifier::PostLoad() and GetAppliedModifier()
