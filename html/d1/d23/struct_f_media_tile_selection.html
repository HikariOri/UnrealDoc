◆ GetVisibleRegions()

TArray< FIntRect > FMediaTileSelection::GetVisibleRegions ( const FMediaTileSelection * InCurrentTileSelection = nullptr) const

Returns a calculated list of contiguous visible tile regions. Only provides regions for the missing tiles if CurrentTileSelection is specified.

This is a two-pass algorithm to batch tiles into contiguous regions, with a bias for row groupings. First, we iterate through visible tiles, and create regions for (horizontally) contiguous tiles in each row. Second, we create the final regions out of (vertically) contiguous row regions of matching width & position.
