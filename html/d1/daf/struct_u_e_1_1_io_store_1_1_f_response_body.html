◆ GetBody()

FIoBuffer UE::IoStore::FResponseBody::GetBody ( ) const
inline

Returns the entire body in a single buffer as it was returned from the CDN.

Note that if the request was multi-part range then this buffer will include the headers for each range. It is up to the caller to manage that.

◆ GetData()

FIoBuffer UE::IoStore::FResponseBody::GetData ( const FIoOffsetAndLength & Range) const

Returns a view of the data for the given range.

The requested range must be within the ranges for the initial request.

◆ GetSize()

uint64 UE::IoStore::FResponseBody::GetSize ( ) const
inline

Returns the total length of the body that was downloaded.

Note that if the request was multi-part range then the body will include additional overhead as each range has it's own small header and so the size will be larger than the sum of the requested ranged.
