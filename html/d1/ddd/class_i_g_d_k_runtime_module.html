virtual HRESULT IGDKRuntimeModule::AsyncGDKTask ( class FGDKAsyncTaskMonitor & OutMonitor,
TFunction< HRESULT(XAsyncBlock *)> InitFunction,
TFunction< void(XAsyncBlock *)> ResultFunction = nullptr,
XTaskQueueHandle TaskQueue = nullptr ) const
pure virtual

Simple wrapper for cancellable async GDK task execution.

参数
OutMonitorvariable that will receive the task monitor, allowing cancellation of the task (ResultFunction will still be called, with E_ABORT)
InitFunctioncode that will be executed on the game thread to start the operation (e.g. XUserAddAsync). Expected to return the result from the GDK async function.
ResultFunctionoptional code that will be executed when the async operation has finished (e.g. XUserAddResult). Execution thread depends on TaskQueue.
TaskQueueoptional task queue. Default is GetGenericTaskQueue which executes on a background thread and ResultFunction happens on the game thread.
返回
the result from InitFunction, so S_OK means the async task has started successfully and ResultFunction will be called

virtual bool IGDKRuntimeModule::WasUserRecentlySignedOut ( XUserLocalId UserLocalId) const
pure virtual

Returns whether the given local user was previously signed in but is not presently signed in

参数
UserLocalIdthe user to query
返回
true if the user had previously signed in but has now signed out. Will return false when the user has completed signing back in
注解
this function uses XUserLocalId because the user handle would be invalid once the user is signed out
