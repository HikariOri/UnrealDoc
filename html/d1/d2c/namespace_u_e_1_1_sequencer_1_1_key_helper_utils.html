bool UE::Sequencer::KeyHelperUtils::TransformKeySelection ( ISequencer & InSequencer,
const TSet< FSequencerSelectedKey > & InKeys,
const FFrameTime & InDeltaTime,
const float InScale,
const bool bInTransact = true )

Transforms the selected keys by applying a time delta and an optional scaling factor. Updates the affected sections' bounds and notifies the sequencer of changes.

参数
InSequencerThe sequencer instance used to transform the keys.
InKeysThe set of selected keys to transform.
InDeltaTimeThe time delta used for translating the keys.
InScaleThe scaling factor applied to the keys.
bInTransactWhether to create a transaction for the transform.
返回
True if any keys were changed, false otherwise.

Transforms either the selected keys or a relative set of keys based on a time delta and scaling factor. If no selected keys are provided, keys relative to the specified time range will be collected and transformed.

参数
InSequencerThe sequencer instance used to transform the keys.
InWeakChannelsA set of weak pointers to channel models that define the scope for collecting keys.
InSelectedKeysA set of keys explicitly selected for transformation.
InDeltaTimeThe time delta used for translating the keys.
InScaleThe scaling factor applied to the keys.
bInTransactWhether to create a transaction for the transform.
返回
True if any keys were changed, false otherwise.
