◆ BeginPackageDiff()

void FDiffPackageWriter::BeginPackageDiff ( const FBeginPackageInfo & Info)
protected

When BeginPackage is called, CommitPackage must be called as well. But sometimes we don't want or don't need to do all this and we just want to initialize the internal variables as if BeginPackage was called. That's what BeginPackageDiff does. For example FIncrementalValidatePackageWriter can use an internal writer so FDiffPackageWriter::BeginPackage/CommitPackage will not be called, but to make sure the internal variables are correct and the object behaves as expected, BeginPackageDiff is called instead.
