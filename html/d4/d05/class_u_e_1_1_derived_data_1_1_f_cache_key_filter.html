FCacheKeyFilter UE::DerivedData::FCacheKeyFilter::Parse ( const TCHAR * Config,

Parses a filter from a configuration string.

Example:

  • Config = "-DDC-Verify=Texture@2.5+StaticMesh -Unused -DDC-Verify=Audio@75"
  • BucketPrefix = "-DDC-Verify="
  • DefaultRate = 50.0f
  • Filter matches Texture at a rate of 2.5%, StaticMesh at a rate of 100%, Audio at a rate of 75%, and everything else at a rate of 50%.
  • Config = "-DDC-All-MissTypes=StaticMesh@50 -DDC-All-MissKeys=Texture/0123456789abcdef0123456789abcdef01234567"
  • BucketPrefix = "-DDC-All-MissTypes="
  • KeyPrefix = "-DDC-All-MissKeys="
  • Filter matches StaticMesh at 50%, the single Texture key specified, and everything else at a rate of 0%.

Multiple buckets or keys in one argument are delimited by '+' or ','.

参数
ConfigThe configuration in the form of command line parameters.
BucketPrefixThe prefix of the parameter to parse the bucket filter from. Disabled if null.
KeyPrefixThe prefix of the parameter to parse the key filter from. Disabled if null.
DefaultRateThe default rate at which to apply the filter. [0, 100]

void UE::DerivedData::FCacheKeyFilter::SetSalt ( uint32 Salt)

Accesses the salt that is combined with the cache key for filtering.

The filter will always produce the same output for a fixed pair of salt and key. To change the behavior of the filter between sessions, the salt is assigned randomly by default.
