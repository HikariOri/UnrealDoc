◆ InputDecayReferenceLagMs

float FNetworkPhysicsSettingsNetworkPhysicsComponent::InputDecayReferenceLagMs = PhysicsReplicationCVars::ResimulationCVars::InputDecayReferenceLagMs

Overrides CVar: np2.Resim.InputDecayReferenceLagMs – Applied when np2.Resim.EnableLagScalingInputDecay is true. Reference lag at which the decay will be exactly InputDecay. Linearly interpolated below, reaching 0 decay at 0 lag. Tries to maintain behavior above that lag, by decaying input more to travel the same distance over greater time for the same input.
