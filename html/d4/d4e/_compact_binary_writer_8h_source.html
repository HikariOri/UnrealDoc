281 // This is a prototype-quality format for the writer. Using an array of bytes is inefficient,
282 // and will lead to many unnecessary copies and moves of the data to resize the array, insert
283 // object and array sizes, and remove field types for uniform objects and uniform arrays. The
284 // optimized format will be a list of power-of-two blocks and an optional first block that is
285 // provided externally, such as on the stack. That format will store the offsets that require
286 // object or array sizes to be inserted and field types to be removed, and will perform those
287 // operations only when saving to a buffer.
