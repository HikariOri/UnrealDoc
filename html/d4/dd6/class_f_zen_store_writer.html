Called during CookByTheBookFinished. Remove Ops from the Oplog that have not been referenced recently and should be removed to save space in the oplog and in artifacts that cache data about packages.

参数
OplogContextInformation that describes which packages were cooked or their previously cooked op inspected (by e.g. incremental cook) in the current cook. The PackageWriter should update the LastReferencedDate for these packages before checking for ops that have not recently been referenced.
