◆ EExpansionPersistenceMethod

enum class FDetailsViewArgs::EExpansionPersistenceMethod : uint8
strong

Enum to set expansion persistence. Used to support saving expansion per details view.

枚举值
Default 

Expansion will use default persistence (Global shared per struct type)

TransientPerViewIdentifier 

Expansion will be stored transiently per details view identifier and persist in a single editor session. The Expansion will be written to EditorPerProjectUserSettings.ini, but will be cleared without read on editor startup.

PersistentPerViewIdentifier 

Expansion will be stored per details view identifier and persist on disk.

◆ ENameAreaSettings

enum FDetailsViewArgs::ENameAreaSettings
枚举值
HideNameArea 

The name area should never be displayed

ObjectsUseNameArea 

All object types use the name area

ActorsUseNameArea 

Actors prioritize using the name area

ComponentsAndActorsUseNameArea 

Components and actors prioritize using the name area. Components will display their actor owner as the name
