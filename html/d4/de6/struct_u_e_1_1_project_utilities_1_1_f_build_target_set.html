详细描述

FBuildTargetSet is a value type that represents a set of build targets, e.g. Server|Client|Editor or Client|Server. The underlying target types are meant to be abstracted away, instead the set can be constructed from a piece of reflection data (e.g. a UFunction to call or UClass to use)
