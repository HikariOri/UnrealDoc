TMap<FString, int32> FPropertyAccessChangeNotify::ElementIndicesMap

Maps each container property's name to the element index affected by this change. Empty for non-container changes. For nested container changes, each container level in the chain contributes one entry, e.g. { "OuterArray" -> 2, "InnerArray" -> 5 }.
