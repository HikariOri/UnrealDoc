◆ GetFullExtensionStartIndex()

int32 UE::IoStore::Private::GetFullExtensionStartIndex ( FStringView Path)

Finds where the extension starts in a path.

We can't just find the left most '.' in the file name because the path might contain a bulkdata cooked index (

参见
FBulkDataCookedIndex) and we don't want to include the index part. We are attempting to match up the extensions with those found in the constructor of FCookedFileStatMap.

For example take the following filenames and the extensions we want to find: <packagename>.m.ubulk -> .m.ubulk <packagename>.o.ubulk -> .o.ubulk <packagename>.001.ubulk ->.ubulk

So we want to find the left most '.' unless that is followed by only numeric values in which case we have found a cooked index and we want to find the '.' after those values.
