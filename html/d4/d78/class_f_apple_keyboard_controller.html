◆ EInitFlags

enum class FAppleKeyboardController::EInitFlags : uint8
strong

Set of flags used to determine how keyboard input events are handled

枚举值
None 

Default option where the internal GC Keyboard key change handler will be initialized

GCKeyboardKeyHandlerDisabled 

If set, the GC keyboard Key Change handler will not be initialized, and this controller will only work with external input events. GC Keyboard will still be used to report if a physical keyboard is connected or not
