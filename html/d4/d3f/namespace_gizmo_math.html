详细描述

GizmoMath functions implement various vector math/geometry operations required to implement various standard Gizmos. Although some of these are standard queries, in the context of user interface Gizmos they may have behaviors (like assumptions about valid ranges or error-handling) that would not be suitable for general-purpose math code.

INTERACTIVETOOLSFRAMEWORK_API void GizmoMath::GetScreenSpaceLineStartEnd ( const FSceneView * InSceneView,
const FVector & InLineOrigin,
const FVector & InLineDirection,
const double & InLineLength,
FVector & OutScreenStartPoint,
FVector & OutScreenEndPoint,
double & OutClampedWorldFraction,
double & OutClampedWorldStartFraction )

Get the screen-space start and end for the given line (from origin, direction, length). Z is depth from view, XY are in pixel space. OutClampedWorldFraction is used when one or more of the end points is beyond the view bounds, and reflects the fraction of the line (in world space) that's visible, ie. if only 50% of the line is within the viewport, this will return 0.5. OutClampedWorldStartFraction reflects the world-space offset from the line origin to the visible segment start - non-zero when the origin end of the line is clipped (e.g. camera-follow mode where the origin leaves the viewport).

RealType & OutHitDepth )

Find the intersection of the ray defined by RayOrigin and RayDirection with the cone defined by ConeCenter, ConeDirection, ConeCosAngle, and ConeHeight. Where ConeCosAngle is the cosine of the cone opening angle, defined as the angle at the apex between the cone's axis and slant edge. Returns intersection success/failure in bOutIntersects and the hit depth parameter along the ray for the first intersection in OutHitDepth.
