详细描述

Container for FPackageDatas in the Load state. Has a single InProgress container, and multiple subqueues which contain pointers to PackagePreloaders of packages which might be requested because they're in the load state, or requested because even though they are in another state (e.g. request or idle), one of the packages in the load state imports them so we want to preload and load them for better load performance of the referencer package.
