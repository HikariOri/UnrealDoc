◆ SetEnabled() [1/2]

void FPropertyPermissionList::SetEnabled ( bool bEnable,
bool bAnnounce = true )

Turn on or off the property PermissionList. DoesPropertyPassFilter will always return true if disabled. Optionally the change can be announced through a broadcast, which is typically recommended, but may not be needed if the permission list is only temporary enabled, e.g. during saving.

Under the hood, it will be a delegate that will always return bEnabled. If a delegate is passed in instead, that delegate is called to return dynamically whether the filter is enabled or not.
