Set bone weights using potentially unnormalized weights. The given weights will be pruned and normalized according to the provided settings. If no settings are provided, default settings will be used.

参数
InVertexIndexThe vertex index to set these weights at.
InWeightsThe raw weights to set.

Blindly set raw weights. The user is responsible to make sure that the weights are normalized. No checking of normalization, maximum weight count, or minimal weight threshold will be performed.
