详细描述

template<typename IntType>
struct UE::Geometry::TIndexMap< IntType >

TIndexMap stores mappings between indices, which are assumed to be an integer type. Both forward and backward mapping are stored

待办事项

make either mapping optional

optionally support using flat arrays instead of TMaps

constructors that pick between flat array and TMap modes depending on potential size/sparsity of mapped range

identity and shift modes that don't actually store anything
