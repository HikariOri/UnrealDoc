◆ GetRemoteObjectId()

COREUOBJECT_API FRemoteObjectId UE::RemoteObject::Handle::GetRemoteObjectId ( TFunctionRef< const UObject *()> CodeThatReturnsRawUObjectPtr)

Advanced use only. If you are in a situation where you are using raw pointer API's that potentially cause migrations, but you need to grab the FRemoteObjectId of that UObject, you can use this function. For the duration of the passed-in CodeThatReturnsRawUObjectPtr, we will disable attempts to resolve remote object pointers. The UObject that is returned from CodeThatReturnsRawUObjectPtr will be converted to a FRemoteObjectId.

参数
CodeThatReturnsRawUObjectPtra short lambda or function that accesses nothing but the single UObject it is returning.
返回
the FRemoteObjectId for the returned value. It can be invalid (in the case of nullptr).
