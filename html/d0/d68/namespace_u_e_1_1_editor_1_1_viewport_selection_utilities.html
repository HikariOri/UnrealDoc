◆ PickColorAndAddLight()

void UE::Editor::ViewportSelectionUtilities::PickColorAndAddLight ( FViewport * Viewport,
const FViewportClick & Click )

This function picks a color from under the mouse in the viewport and adds a light with that color. This is to make it easy for LDs to add lights that fake radiosity.

参数
ViewportViewport to pick color from.
ClickA class that has information about where and how the user clicked on the viewport.
