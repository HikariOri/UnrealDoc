详细描述

Holds size, tiling, and mip-count information for a single tiled media sequence.

Note: This type is engine-internal. It lives in MediaAssets/Internal so that media plugins (ImgMedia, MediaPlate, future preview viewports) can share it without forcing it into the public API surface.
