◆ PreVisibilityTasks()

void FSceneCullingRenderer::PreVisibilityTasks ( FRDGBuilder & GraphBuilder)
overridevirtual

Called before LaunchVisibilityTasks to allow scene extensions to prepare data for use during these steps. Note that because of the visibility tasks being launched as early as possible, this can happen before the end of FScene::Update, Notably, it happens (when done early) after SceneExtensionsUpdaters.PostSceneUpdate and before GPU-Scene update, in the callback Parameters.Callbacks.PostStaticMeshUpdate. Thus, you can always rely on the updaters to have processed scene updates, but nothing after that sequencing point.
