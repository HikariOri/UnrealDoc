bool FClassViewerNode::bPassesFilterRegardlessTextFilter

true if the class passed all the sub-filters of the filter (regardless of the TextFilter one). This could be useful to verify e.g., that the parent class of a IsNodeAllowed() object is also valid (even though that parent will not likely pass the TextFilter).
