119// A collection of graph properties used by a value.
120//
121// If a graph property is true, it generally means that either the value itself makes has of that
122// property, or one of its dependencies (direct or indirect) has it. This entails these flags are
123// automatically propagated to all dependant values (values that depend on a given one). As an
124// example, if "ReadsPixelNormal" is true on a specific value it means that either that value
125// itself or some other upstream value that value is dependent on reads the pixel normal.
126//
127// The properties starting with "Uniform" are exceptions. Instead of being a union of child subgraph
128// properties, "Uniform" represents an intersection, indicating *all* dependencies have "Uniform" set,
129// as opposed to any. "PreshaderOut" is set for "Uniform" nodes with an immediate non-Uniform parent,
130// and "PreshaderTemp" is set for nodes in a subtree of a "PreshaderOut" node, representing
131// intermediate values that don't need to be available on the GPU or in the output uniform buffer.
132// And "TrivialTailSwizzle" handles a special case optimization.
133enum class EGraphProperties : uint8
134{
135 None = 0,
136
137 // This value is only meaningful and available in the pixel stage.
138 PixelStageOnly = 1 << 0,
139
140 // Some value reads the pixel normal.
141 ReadsPixelNormal = 1 << 1,
142
143 // Some value in the subtree is a parameter.
144 HasParameter = 1 << 2,
145
146 // This value and all its dependencies have the Uniform property set.
147 Uniform = 1 << 3,
148
149 // This value is used as an output in a Preshader, meaning it's visible to the GPU and needs a uniform buffer location.
150 // Set if Uniform and HasParameter are both set, and the value is used by a non-Uniform.
151 PreshaderOut = 1 << 4,
152
153 // This value is used as a temporary in a Preshader, meaning it is only used by other Preshaders, and HLSL doesn't
154 // need to be generated for it. An exception is if TrivialTailSwizzle below is also set. Set for values in a
155 // subtree of a PreshaderOut, exclusive with PreshaderOut, which takes precedence.
156 PreshaderTemp = 1 << 5,
157
158 // This value is a trivial tail swizzle, meaning a subscript or composite of elements from a single source vector
159 // (and optionally any number of constant elements) at the root of a subexpression tree that can be expanded on the
160 // GPU for "free". Forces the code required to expand the value to be emitted to the GPU, even if also a PreshaderTemp.
161 TrivialTailSwizzle = 1 << 6,
162};
