226 /*
227 * Cancels an in-flight patching operation. Patching work on individual files that has already started will run to completion
228 * however any files that have not started patching will be skipped. Even after cancelling, one must wait for the patcher to complete
229 * by waiting on the GetPatchingTask() explciitly or until IsPatching returns false.
230 *
231 * @return true if an in-flight patching operation was cancelled. If no patching operation is underway, returns false.
232 */
233 bool CancelPatching()

242
243 return true;
244 }
