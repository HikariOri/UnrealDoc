◆ ELandscapeWeightBlendPaintMode

enum class ELandscapeWeightBlendPaintMode
strong
枚举值
UMETA 

Exclusive Mode for weight-blended layers will be active only when the Ctrl key is held. Non-Exclusive Mode is used otherwise. Note : this mode is incompatible with LandscapeEditorControlType "RequireCtrl" since the Ctrl key is then reserved for activating the landscape tools in that case. Use one of the manual modes in that case.

UMETA 

Exclusive Mode for weight-blended layers will be active only when the Ctrl key is not held. Non-Exclusive Mode is used otherwise. Note : this mode is incompatible with LandscapeEditorControlType "RequireNoCtrl" since the Ctrl key is then reserved for activating the landscape tools in that case. Use one of the manual modes in that case.

UMETA 

Force use Exclusive Mode for weight-blended layers. The Ctrl key is ineffective in that mode.

UMETA 

Force use Non-Exclusive Mode for weight-blended layers. The Ctrl key is ineffective in that mode.
