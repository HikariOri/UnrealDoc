enum class EHttpServerResponseFlags : uint8
strong
枚举值
None 
MultipleWriteStream 

Used to indicate the response body will consist of multiple writes before another read/close (possibly an SSE stream)

HasAdditionalWrites 

Used to indicate if additional stream writes are expected, used with MultipleWriteStream

SkipHeaderWrite 

Used to indicate if the next response write should skip including headers, used with MultipleWriteStream

CloseAfterWrite 

Destroy the connection immediately after this response is written, bypassing the keep-alive return to AwaitingRead. Required for streaming responses (MultipleWriteStream) that emit neither Content-Length nor Transfer-Encoding: chunked framing: HTTP/1.1 clients fall back to read-to-EOF semantics for unframed bodies, so the socket close is the only end-of-message signal they receive. Without this flag, the socket idles until FHttpConnection::ConnectionKeepAliveTimeout (15s) elapses, masking the response delivery. Set on the final write of a streaming sequence.
