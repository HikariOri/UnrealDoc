18/*
19 * HOW TO DEBUG NAVIGATION EVENTS
20 * Test the static result via FSlateNavigationEventSimulator.
21 * If the simulation doesn't work, your widget is probably not be configured properly.
22 * If the simulation does work, use the "WidgetReflector events log" or the "Console Slate Debugger" to get information on the navigation event while playing.
23 * A - If you do not find the event, check it has been consumed by the viewport or by a widget with OnKeyDown.
24 * B - If you find the event, note if the Reply and Consumed widget are different.
25 * i- If they are different, then use the "WidgetReflector routing" tool to understand why another widget has consumed the routing.
26 * For example, the widget can be disabled or it may have a custom OnNavigation event.
27 * ii- If they are not different, then the GameViewportClient or the application may have consumed the event.
28 * You may also check if you received the focus event with the "WidgetReflector events log" or with the "Console Slate Debugger".
29 */
