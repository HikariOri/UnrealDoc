详细描述

This class wraps the server thread and network connection.

It uses ITargetDeviceSocket to exchanging data with the connected targets. This interface is an abstraction for direct pc-target communication as provided by the platforms. IPlatformHostCommunication/IPlatformHostSocket are the corresponding interfaces used on the game side.

This implementation is based on FNetworkFileServer (the TCP-based server).
