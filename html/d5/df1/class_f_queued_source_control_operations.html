详细描述

This class is a utility for UResavePackagesCommandlet to make it easier to batch up source control requests as it is significantly more efficient to perform the same operation on a large number of files at once rather than send a single request per file.

The size of the batches are controlled by either the number of packages stored or the amount of temporary disk space that the queued requests are taking up, which ever limit is reached first.

◆ QueueCheckoutAndReplaceOperation()

void FQueuedSourceControlOperations::QueueCheckoutAndReplaceOperation ( const FString & FileToCheckout,
const FString & ReplacementFile,
UPackage * Package = nullptr )

Add a file to a list of files to be checked out from source control at a point in the future and to be replaced with another file once the checkout has been completed.

In order to speed up processing a pointer to the loaded UPackage for the file can be provided, if it is not then the eventual checkout operation will need to try finding the UPackage via the filename which will be slower.

参数
FileToCheckoutThe path of the file to check out in source control
ReplacementFileThe path of a temporary file to be written over 'FileToCheckout' once it is checked out. NOTE that the file will be deleted on either success or failure!
PackageA pointer to the loaded UPackage for the file (optional)
