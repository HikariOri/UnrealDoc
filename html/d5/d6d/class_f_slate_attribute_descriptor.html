◆ TNestedAttributeValueChangedDelegateTyped

A delegate similar to FAttributeValueChangedDelegate but for nested attributes. The main difference is that a reference to the object owning the nested attribute is also passed as an argument. This templated version already converts the owning widget to the right type.
