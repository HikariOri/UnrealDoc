void SequencerHelpers::SortOutlinerItems ( FSequencer & Sequencer,

const bool bInSortByItemOrder,
const bool bInDescending,
const bool bInTransact = true )
static

Sorts an array of outliner items by start time of the first layer bar or selection order

参数
SequencerThe Sequencer that the outliner items belong to
InItemsThe list of outliner items to sort
bInSortByItemOrderIf true, sorts by the order of the item in the array instead of by start time of the layer bar
bInDescendingIf true, sorts in reverse order instead of ascending
bInTransactIf true, creates an editor transaction that can be undone

Represents a layer bar. Holds cached pointers for element operations.
