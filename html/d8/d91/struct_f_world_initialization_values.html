uint32 FWorldInitializationValues::bAllowLumenPrimitiveTrackingInPreviewWorld

Allows LumenSceneData to set bTrackAllPrimitives even if the world is a preview world. This makes it possible to populate the Lumen surface cache and use Lumen in preview worlds, e.g. asset editor viewports.
