MediaBuffering 

The media source started buffering data.

The media source completed buffering data.

MediaClosed

MediaConnecting 

The player started connecting to the media source.

MediaOpened 

A new media source has been opened.

MediaOpenFailed 

A media source failed to open.

PlaybackEndReached

PlaybackSuspended

SeekCompleted

TracksChanged

MetadataChanged
