bool FNetDriverReplicationSystemConfig::bAllowParallelTasks = false

When true, allow subsystems to run parallel workloads, such as the PollAndCopy step running several asynchronous tasks to speed up game thread execution time. Only supported when bIsServer = true and bAllowObjectReplication = true

◆ MinConnectionsForParallelTick

int32 FNetDriverReplicationSystemConfig::MinConnectionsForParallelTick = 2

Sets the minimum amount of connected clients before we start executing NetConnection::Tick in parallel. This limits the overhead of kicking off parallel tasks when concurrency gains would be limited. Default is to wait for 2 connections.
