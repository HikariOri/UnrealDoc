template<class NodeType, bool AllowNull, class AllocatorType, typename... AllocatorArgsType>
struct Verse::Vst::TNodePtrG< NodeType, AllowNull, AllocatorType, AllocatorArgsType >

Reference-counted smart pointer to a Vst::Node or any type descended from it.

Use TNodeRef<T> (non-nullable) and TNodePtr<T> (nullable) aliases below rather than instantiating TNodePtrG directly.
