详细描述

Knows of all filter bar instances that need to be run in Sequencer. This is relevant for multiple UI endpoints using the linked filtering system.

Each endpoint can register a filter bar they want evaluated, and request explicit refreshes. The evaluator will be refreshed next tick by Sequencer.

参见
IncrementFilterBarUsage, DecrementFilterBarUsage

If your filter UI becomes hidden (e.g. tab in background), as optimization, it would be valid to call DecrementFilterBarUsage and follow it up again with a IncrementFilterBarUsage once the UI becomes active again.

Tracks a filter bar that some UI endpoints is displaying filter results for.

If this is already tracked, increments the usage counter by 1. If previously untracked, this creates a subscription ISequencerFilterBar::OnRequestUpdate.
