详细描述

Struct used to configure which NetDriver is started with Iris enabled or not Only one attribute out of the NetDriverDefinition, NetDriverName or NetDriverWildcardName should be set along with the bEnableIris property

bool FIrisNetDriverConfig::bCanUseIris = false

Configurable property that decides if the NetDriver will use the Iris replication system or not if Iris is enabled

◆ bCanUseParallelNetConnectionTick

bool FIrisNetDriverConfig::bCanUseParallelNetConnectionTick = false

If true, and Iris is used as the replication system then NetConnection::Tick can be run in parallel on the server for this NetDriver

◆ PreferredReplicationSystem

EReplicationSystem FIrisNetDriverConfig::PreferredReplicationSystem = EReplicationSystem::Default

Sets the preferred replication system for this NetDriver. This is the one that will be used unless it's overridden by bCanUseIris, UGameInstance::GetDesiredReplicationSystem, or AGameModeBase::GameNetDriverReplicationSystem.
