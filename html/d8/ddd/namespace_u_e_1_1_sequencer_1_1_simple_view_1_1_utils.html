◆ BlendColors()

FLinearColor UE::Sequencer::SimpleView::Utils::BlendColors ( const FLinearColor & InColorA,
const FLinearColor & InColorB,
const float InPercent = .5f )

Blends two colors together based on a specified percentage.

参数
InColorAThe first input color to be blended.
InColorBThe second input color to be blended.
InPercentA percentage value (0.0 to 1.0) that determines the influence of InColorB over InColorA. 0.0 will return InColorA, while 1.0 will return InColorB.
返回
The resulting color after blending InColorA and InColorB using the specified percentage.

◆ WhitenColor()

FLinearColor UE::Sequencer::SimpleView::Utils::WhitenColor ( const FLinearColor & InColor,
const float InPercent = .5f )

Adjusts the given color by blending it with white, based on the specified percentage.

参数
InColorThe input color to be adjusted.
InPercentA percentage value (0.0 to 1.0) that determines the influence of white on the input color. 0.0 will return the original color, while 1.0 will return pure white.
返回
The resulting color after blending the input color with white by the given percentage.
