◆ MaxExecutionPriority

int32 FMassProcessorDependencySolver::FNode::MaxExecutionPriority = 0

The highest execution priority across this node and all nodes in its logical dependency chain. Nodes that are only dependencies due to resource contention (i.e. blocking shared resources) are excluded from this calculation. Note: we use int32 rather than UMassProcessor.ExecutionPriority's int16 to avoid overflow when propagating priorities in UpdateExecutionPriority.
