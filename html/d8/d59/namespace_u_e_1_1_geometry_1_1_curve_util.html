Project the QueryPoint to the given curve, reporting squared distance, segment, and closest point

参数
VerticesVertices of the curve
bLoopWhether the curve is a loop (i.e., whether we should include a segment from the last vertex to the first)
QueryPointPoint to query for distance from curve
OutDistanceSqSquared distance to query point
OutNearestSegIndexIndex of the nearest segment on the curve, or INDEX_NONE if the curve has no segments (has length < 2)
OutNearestPointThe nearest point on the curve
OutNearestSegmentUnitParamThe 'unit parameter' along the closest segment – i.e. the parameter from 0 to 1 that you would pass to a Lerp to get the closest point on that segment
OutNearestSegmentParamIf non-null, will be set to the 'segment parameter' along the closest segment – i.e. the parameter from -SegmentExtent to +SegmentExtent where 0 is the segment midpoint
返回
true if a closest point was found (i.e. if the curve had vertices)
