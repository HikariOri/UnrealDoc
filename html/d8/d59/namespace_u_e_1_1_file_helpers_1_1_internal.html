◆ FGetAdditionalInteractiveSavePackageCandidates

using UE::FileHelpers::Internal::FGetAdditionalInteractiveSavePackageCandidates = TMulticastDelegate<void(TSet<UPackage*>& OutPackages)>

Low-level delegate called by FEditorFileUtils::GetDirtyXPackages to collect additional candidates to save if dirty.

注解
This doesn't forcibly add any candidates to the dirty/save lists, but may allow them to bypass certain filtering that would have otherwise removed them (eg, to allow an empty actor package).
参数
OutPackagesThe set of additional candidates, to be filled by the callback.
