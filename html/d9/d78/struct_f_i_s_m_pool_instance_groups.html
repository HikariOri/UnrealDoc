详细描述

Structure containing a set of allocated instance ranges in an FISMPoolMeshISM which is the manager for a single ISM component. The instance ranges don't change once allocated, and aren't the same as the actual render indices in the ISM. The reason that we don't store the the actual ISM render indices is that ISM component is free to reorder its instances whenever it likes.
