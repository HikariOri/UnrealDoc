◆ AcquireWindowForRHI()

uint32 FLinuxPlatformApplicationMisc::AcquireWindowForRHI ( void * SdlWindow)
static

Register that an RHI surface now backs this window. Called from the RHI right after a Vulkan surface is created for the window. Thread-safe (RHI thread). Returns the SDL window id the ref was recorded under (0 on failure). Release must be keyed on this immutable, never-recycled id (the RHI carries it on the window context / swapchain) rather than on a pointer that may be stale or reused by destroy time.

Mark a window for destruction once all RHI surface refs are released. The actual SDL_DestroyWindow runs on the game thread in PumpMessages once the refcount reaches zero (or a wall-clock backstop elapses). Replaces the old fixed-frame defer.

◆ ReleaseWindowForRHI()

void FLinuxPlatformApplicationMisc::ReleaseWindowForRHI ( uint32 WindowId)
static

Release an RHI surface ref for the window previously acquired under WindowId. Called from the RHI right after the Vulkan surface is destroyed. Thread-safe (RHI thread). Never destroys the window itself. Keyed on the immutable, never-recycled SDL window id, so a release that arrives after the window is already gone (e.g. via the destroy backstop) is a safe no-op and can never decrement a different window's refcount.
