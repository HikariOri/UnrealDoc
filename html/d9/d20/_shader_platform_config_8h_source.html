10// Shader Platform Configuration
11//
12// Similar to DataDrivenShaderPlatformInfo (DDSPI), but settings come from Engine config hierarchy. DDSPI is specifically for immutable shader platform
13// capabilities, while SPC is for shader platform configuration.
14//
15// Configs are stored in one section per shader platform with the same names that DDSPI uses.
16// ex: [ShaderPlatform PCD3D_SM6] -> [ShaderPlatformConfig PCD3D_SM6]
17//
18// Interface initially built with static getters but those use per-platform structs with getters. While the static getters suffice for initial adoption, the
19// ideal usage would be passing the per-platform struct around to code that needs them. This usage would make it easier to adopt "custom shader platforms" in
20// the future.
21//
22// New fields need the following:
23// 1. Value inside FPlatformConfig
24// 2. Member getter inside FPlatformConfig
25// 3. Static getter inside FShaderPlatformConfig
26// 4. Default value inside FShaderPlatformConfig::FPlatformConfig::SetDefaultValues
27// 5. Initialization inside FShaderPlatformConfig::FPlatformConfig::InitializeProperties
28// 6. (optional) Engine defaults inside Base{Platform}Engine.ini
29// 7. (optional) Preview override inside FShaderPlatformConfig::FPlatformConfig::InitializePropertiesForPreview
30//
