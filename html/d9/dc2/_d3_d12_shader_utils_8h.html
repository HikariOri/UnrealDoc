Build a serialized root signature for a compute shader from its UE shader blob. Uses the same root signature construction logic as RHICreateComputeShader.

参数
ShaderCodeFull UE shader blob (SRT + native bytecode + optional data)
ResourceBindingTierResource binding tier to use for the root signature layout
OutRootSigBlobReceives the serialized root signature blob
OutNativeBytecodeOffsetReceives the offset to native DXBC/DXIL bytecode within ShaderCode
返回
true on success
