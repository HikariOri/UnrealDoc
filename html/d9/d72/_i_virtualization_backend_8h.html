This macro can be used to change the config name used to create backends while allowing older config file entries to continue working. If this factory is used to instantiate a backend then we will log a warning to the user so that they can update their config file.

参数
BackendClassThe name of the class derived from 'IVirtualizationBackend' that the factory should create.
LegacyConfigNameThe old name that 'ConfigName' is now replacing.
ConfigNameThe name used in config ini files to reference this backend type.
