FRDGTextureRef OutputVelocityTexture,
EShaderPlatform ShaderPlatform )

Resolves motion vector world offset and writes the merged velocity into an output texture. The SLW variant writes only to pixels that have MVWO data, leaving the rest untouched.

参数
StandardVelocityTextureContains standard velocity
MVWOOffsetTextureContains the MVWO offset
OutputVelocityTextureReceives the merged velocity. Only pixels with MVWO data are written.
