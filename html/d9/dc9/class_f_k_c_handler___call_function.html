This code is for property dirty tracking. It works by injecting in extra nodes while compiling that will call UNetPushModelHelpers::MarkPropertyDirtyFromRepIndex. See FKCPushModelHelpers::ConstructMarkDirtyNodeForProperty for node generation.

If we're passing net properties as reference variables, there's no guarantee what the function will do, so we won't actually know whether or not the value has changed. In that case we'll go ahead and mark the property as dirty.
