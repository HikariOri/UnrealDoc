详细描述

UGC localization can be used to provide a simplified localization experience for basic plugins (only providing the PO files to be translated), and is primarily designed for DLC plugins where the UGC localization will be compiled during cook (

参见
UUserGeneratedContentLocalizationSettings).

Support for non-DLC plugins can be provided via project specific tooling built upon this base API. Support for complex plugins (such as those containing different kinds of modules, eg) a mix of game/engine and editor) are not supported via this API.

Merge the PO file data of two UGC localization targets together, so that any PO entries with translations from source are present in dest. Whether the translation from source is actually applied to dest depends on the MergeMode.

注解
Dest does not have to currently exist prior to the merge.
参数
SourceLocalizationTargetNameThe name of the source localization target (
参见
GetLocalizationTargetName).
参数
SourceLocalizationTargetDirectoryThe directory of the source localization target (
参见
GetLocalizationTargetDirectory).
参数

参见
GetLocalizationTargetName).
参数
DestLocalizationTargetDirectoryThe directory of the dest localization target (
参见
GetLocalizationTargetDirectory).
参数
MergeModeWhen should an existing translation from source be applied to dest?
bOnlyIfSourceFileNewerTrue if we should only merge from source -> dest if the source file is newer than the dest file.
bUseSourceControlPass false as an optimization if you knew for certain that DestLocalizationTargetDirectory is outside of source control, otherwise pass true.
