bool FFontEditorViewportClient::InputKey ( const FInputKeyEventArgs & EventArgs)
overridevirtual

Allow the viewport-client to process a key event received by the viewport. If the viewport-client uses the event, it should return true. If true is returned, the viewport should not bubble the event.

参数
EventArgs- The Input event args.
返回
True to consume the key event, false to pass it on.
