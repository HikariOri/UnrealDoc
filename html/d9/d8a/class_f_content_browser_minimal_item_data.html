详细描述

Minimal representation of a FContentBrowserItemData instance for comparison purposes.

注解
Unlike FContentBrowserItemDataKey this does consider the data source, and unlike FContentBrowserItemKey it considers the data source for folder items. It can be used to identify a FContentBrowserItemData for removal from an FContentBrowserItem
