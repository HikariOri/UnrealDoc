inline

A lot of this is similar to FSectionContextMenu::AddKeyInterpolationMenu or FSectionContextMenu::BuildKeyEditMenu, but we can't reuse those directly because this menu is driven by Toolable Timeline key selection, not the standard Sequencer section/context-menu selection path, and it needs to operate on the exact selected key handles across grouped channels rather than the broader section/key-area state those helpers assume. @TODO: Extract common key interpolation menu building logic into a reusable helper functions/class.
