详细描述

Atomic bitset backing the per-asset flags on FStreamingRenderAsset. The previous design used plain ': 1' bitfields packed into shared bytes; concurrent writes from the game thread and the streaming async task to different bits in the same byte would collide via read-modify-write stores and could trash each other's updates. fetch_or / fetch_and on a single std::atomic<uint16> give a true atomic single-bit update on every supported platform (LOCK OR on x86-64, LL/SC retry loop on ARM64). Each bit is a stand-alone flag with no other data coordinated through it, so std::memory_order_relaxed is sufficient; cross-thread happens-before is provided by the task-graph sync event around FRenderAssetStreamingMipCalcTask.
