详细描述

template<typename TScopeLockType>
class UE::AssetRegistry::TRWScopeLockWithPriority< TScopeLockType >

Keeps an FRWLock read-locked while this scope lives. This is almost a clone of the existing FReadScopeLock and similar types however this adds an extra flag to help the background processing thread know when a higher priority thread would like to gain access to the protected data
