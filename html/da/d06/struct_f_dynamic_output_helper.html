◆ GetPinClass()

UClass * FDynamicOutputHelper::GetPinClass ( UEdGraphPin * Pin)
static

Attempts to pull out class info from the supplied pin. Starts with the pin's default, and then falls back onto the pin's native type. Will poll any connections that the pin may have.

参数
PinThe pin you want a class from.
返回
A class that the pin represents (could be null if the pin isn't a class pin).
