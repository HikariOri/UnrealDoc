详细描述

template<typename ElementType>
class TTypedBlockAllocatorFreeList< ElementType >

A TTypedAllocatorBase with a freelist. Freed elements are destructed, but their memory is reused and the constructor called again on it in future allocation.

In this subclass, destructors for allocated elements are not automatically called; users of the allocator must call destructor manually or must call DeleteElement on each element they called NewElement on.
