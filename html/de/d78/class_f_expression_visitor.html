详细描述

This is the base class used for IFExpressionNode tree traversal (set up to handle different node types... new node types should have a Visit() method added for them).

成员枚举类型说明

◆ EVisitPhase

enum FExpressionVisitor::EVisitPhase

FExpressionNodes determine when a traverser (FExpressionVisitor) has access to the node. There are a couple hook points, allowing the traverser to pick either a pre-order or post-order tree traversal. These values let the FExpressionVisitor where we are in the tree search.
