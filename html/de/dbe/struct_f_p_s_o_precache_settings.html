◆ CustomDepthMode

int32 FPSOPrecacheSettings::CustomDepthMode = 1

Precache custom depth PSO permutations 0: No PSOs are compiled 1: PSOs are compiled for all primitives which explicitly request custom depth rendering (PSOs are precached again on custom depth toggle on component) (default) 2: PSOs are compiled for all primitives which also request regular depth rendering

◆ GlobalShaderMode

int FPSOPrecacheSettings::GlobalShaderMode = 1

Precache global shaders 0: no precaching 1: All global compute and subset of global graphics PSOs for which PSO collector is defined (default) 2: All global compute and global graphics shaders (only available when r.PSOPrecache.Mode == 1 (Preload shaders))

int32 FPSOPrecacheSettings::ParticlePrecachingTime = 3

Controls when PSO precaching happens for Niagara/Cascade particles systems: 0: no precaching 1: precaching at component proxy creation time only 2: precaching at component loading time 3: precaching at asset loading time and component time (default)
