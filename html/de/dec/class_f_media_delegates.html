◆ OnMediaTextureResourceReleased_RenderThread

FMediaDelegates::FOnMediaTextureResourceReleasedDelegate FMediaDelegates::OnMediaTextureResourceReleased_RenderThread
static

Fires from FMediaTextureResource::ReleaseRHI immediately before the intermediate render target's RHI reference is dropped. Subscribers receive the FRHITexture* while it is still valid and must not retain it past the callback. Lets a subscriber drop per-texture GPU state while the underlying resource is alive (e.g. unmap reserved-resource tiles), avoiding stale-pointer dereference during process-exit drain.
