18// When asking the Horde server for a machine, this will be returned when the HTTP
19// reponse comes back (after a machine request). If the response didn't come through
20// (i.e., Horde was unable to assign a machine or something), then:

22// - Port will be set to 0xFFFF
23// - Nonce will be all 0

37 };
