详细描述

This implements a remote execution interface for Derived Data Build using Zen Structured Compute interfaces to get work done.

All build actions are typically submitted to the same Zen server which is responsible for build outputs (Project Store) and local DDC. This Zen server is responsible for dispatching the work elsewhere but can also execute it locally when appropriate.

The current implementation uses the "legacy" REST API for simplicity, but should be upgraded to use the new queue-oriented API as soon as possible since that is more efficient and more flexible.
