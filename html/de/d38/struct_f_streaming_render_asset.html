◆ Flags

FStreamingRenderAssetFlags FStreamingRenderAsset::Flags

Atomic bitset holding all the per-asset boolean flags. See FStreamingRenderAssetFlags::EBit for the bit assignments and category (1)-(5). Accessed only via GetFlag / SetFlag, which issue single-bit atomic loads / fetch_or / fetch_and stores immune to the read-modify-write byte-store races that the old ': 1' bitfield layout exposed when GT and async-task threads touched bits in the same byte.
