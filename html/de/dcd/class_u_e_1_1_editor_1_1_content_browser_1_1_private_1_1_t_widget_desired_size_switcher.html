template<EAxis::Type Axis>
class UE::Editor::ContentBrowser::Private::TWidgetDesiredSizeSwitcher< Axis >

Returns a size override to bind to based on a single subject widget's desired size, clamped between a provided size range. If a reference widget is provided, it's (allotted, not desired) size is used for the range max value. Axis is 0 for x/width, 1 for y/height.
