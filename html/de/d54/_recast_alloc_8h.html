◆ rcAllocHint

enum rcAllocHint

Provides hint values to the memory allocator on how long the memory is expected to be used.

枚举值
RC_ALLOC_PERM 

Memory will persist after a function call.

RC_ALLOC_TEMP 

Memory used temporarily within a function.
