Helper struct to sub step through Montages when advancing time. These require stopping at sections and branching points to potential jumps and loops. And also stepping through TimeStretchMarkers to adjust play rate based on TimeStretchCurve.

Invalidate Cached_CombinedPlayRate to force data to be recached in 'ConditionallyUpdateCachedData'

Updates markers P_Marker_Original and P_Marker_Target only* if T_Target has changed.

Finds montage position in 'target' space, given current position in 'original' space. This means given a montage position, we find its playback time. This should only be used for montage position, as we cache results and lazily update it for performance.

Finds montage position in 'original' space, given current position in 'target' space. This means given a montage playback time, we find its actual position. This should only be used for montage position, as we cache results and lazily update it for performance.

Gets current section end position in target space. this is lazily cached, as it can be called every frame to test when to blend out.
