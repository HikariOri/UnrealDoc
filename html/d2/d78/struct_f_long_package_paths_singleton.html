◆ MountPoints

TSet<UE::PackageName::FMountPointKeyByPtr> FLongPackagePathsSingleton::MountPoints

Set of all MountPoints, possibly unmounted, looked up by SearchKey={LongPackageName,LocalPath}. Elements added later are assigned a higher priority and will be the ones findable in RootPathTree and ContentPathTree if they have the same LongPackageName or LocalPath as another MountPoint. This override system allows aliasing both of two LocalPaths that go to the same LongPackageName and two LongPackageNames that go to the same LocalPath.
