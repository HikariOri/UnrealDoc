◆ bForceNewHandle

bool UE::Net::FRootObjectReplicationParams::bForceNewHandle = false

Set to true to prevent the replication system from reusing a NetRefHandle previously assigned to the object. Useful if the object had stopped replicating and that old representation is considered to be destroyed.

◆ bIsDormant

bool UE::Net::FRootObjectReplicationParams::bIsDormant = false

Whether the object is dormant or not

◆ bNeedsPreUpdate

bool UE::Net::FRootObjectReplicationParams::bNeedsPreUpdate = false

Actor only When true the actor will receive a PreReplication callback just before it gets polled.

◆ bNeedsWorldLocationUpdate

bool UE::Net::FRootObjectReplicationParams::bNeedsWorldLocationUpdate = false

When true the object has a dynamic world location and we should ask the factory to update its current location every time it is polled.

◆ bUseClassConfigDynamicFilter

bool UE::Net::FRootObjectReplicationParams::bUseClassConfigDynamicFilter = true

Ask the class config for a dynamic filter assigned to this class or one of it's parent class. Default is true.

◆ bUseExplicitDynamicFilter

bool UE::Net::FRootObjectReplicationParams::bUseExplicitDynamicFilter = false

When enabled we ignore the class config for this object and instead use the one specified by ExplicitDynamicFilter

◆ ExplicitDynamicFilterName

FName UE::Net::FRootObjectReplicationParams::ExplicitDynamicFilterName

The name of the dynamic filter to use for this object (instead of asking the class config). Can be none so that no dynamic filter is assigned to the object. Only used when bUseExplicitDynamicFilter is true.

◆ PollFrequency

float UE::Net::FRootObjectReplicationParams::PollFrequency = 0.0f

How often per second the object should be polled for dirtiness, including calling the InstancePreUpdate function. When set to zero it will be polled every frame.

◆ StaticPriority

float UE::Net::FRootObjectReplicationParams::StaticPriority = 0.0f

If StaticPriority is > 0 the ReplicationSystem will use that as priority when scheduling objects. If it's <= 0.0f one will look for a world location support and then use the default spatial prioritizer.
