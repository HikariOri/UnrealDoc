template<int IndexSize, typename SubClass>
UE_NODEBUG UE_FORCEINLINE_HINT void TSizedAllocatorBase< IndexSize, SubClass >::ForAnyElementType::MoveToEmpty ( SubClass::ForAnyElementType & Other)
inline

Moves the state of another allocator into this one. The allocator is the same class.

Assumes that the allocator is currently empty, i.e. memory may be allocated but any existing elements have already been destructed (if necessary).

参数
Other- The allocator to move the state from. This allocator should be left in a valid empty state.
