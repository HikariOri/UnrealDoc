◆ Initialize()

virtual void FTargetPlatformManagerModule::Initialize ( )
inlinevirtual

Performs all module setup (SDK validation, platform discovery, format loading), called after the module is loaded and before any other methods are used. Separating this from construction allows the async UBT process (kicked off via FDelayedAutoRegisterHelper) more time to finish before we block waiting for it.
