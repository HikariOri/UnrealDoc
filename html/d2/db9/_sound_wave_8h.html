◆ FSoundWaveProxyPtr

using FSoundWaveProxyPtr = TSharedPtr<FSoundWaveProxy, ESPMode::ThreadSafe>

The proxy acts as a broker between the USoundWave and Proxy Readers. if UE_USOUNDWAVE_HOT_RELOADING_ENABLED is true, then proxy clients can use this to query the availablity of new FSoundWaveData, and optionally update to that data.

This lets editor changes and re-imports take effect on even playing sounds.

In these scenarios, the owning USoundWave has its "working" (un-published) copy of FSoundWaveData For changes, and then calls "Publish()" to make this available
