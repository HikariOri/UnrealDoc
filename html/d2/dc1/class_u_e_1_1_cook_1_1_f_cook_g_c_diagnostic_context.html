详细描述

Holds information about the cookers garbage collection status, and communicates requests from low level structures back up to the CookCommandlet that is capable of acting on those requests with additional garbage collection commands.

◆ TryRequestFullGC()

bool UE::Cook::FCookGCDiagnosticContext::TryRequestFullGC ( )

Add a request to reexecute the current GC after all of the PostGarbageCollect calls run and control returns back to the caller of CollectGarbage, and with soft GC turned off. Returns false if not currently in post-GC, or the garbage collect that just ran already was a full GC.

◆ TryRequestGCWithHistory()

bool UE::Cook::FCookGCDiagnosticContext::TryRequestGCWithHistory ( )

Add a request to reexecute the current GC after all of the PostGarbageCollect calls run and control returns back to the caller of CollectGarbage, and with history turned on. Returns false if not currently in post-GC, or the garbage collect that just ran already had history.
