template<class T>
class FDelegatedConsoleVariable< T >

A thin console variable that delegates all reads to a Getter and all writes to a Setter. No history, no priority tracking, no platform value caching - the external source is authoritative. Inherits from FConsoleVariableBase for flags, help text, and change callbacks only.
