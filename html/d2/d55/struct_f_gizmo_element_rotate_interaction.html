◆ Direction

TOptional<FVector2D> FGizmoElementRotateInteraction::Direction

The explicit drag direction corresponding with view-relative rotation. (1.0, 0.0) means left-to-right movement rotates clockwise, right-to-left moves counter-clockwise. Vertical movement wouldn't do anything. Only applicable to Pull rotation. If not set, uses a "pull-string" approach where the direction is determined by the cursor position relative to the origin.
