详细描述

This class creates a tree structure that is used to store cached filter results in such a way that they can be looked up using all the relevant context data that determines how items are filtered. each node has a type agnostic key so that we can easily change how the cache is keyed. (See FActionFilterCache::GetIsFilteredByThisCache)
