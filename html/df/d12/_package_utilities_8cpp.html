Takes an array of package names (in any format) and converts them into relative pathnames for each package.

参数
PackageNamesthe array of package names to normalize. If this array is empty, the complete package list will be used.
PackagePathNameswill be filled with the complete relative path name for each package name in the input array
PackageWildcardif specified, allows the caller to specify a wildcard to use for finding package files
PackageFilterallows the caller to limit the types of packages returned.
返回
true if packages were found successfully, false otherwise.
