Move the variable with the given guid in the struct to be immediately above or below another variable.

参数
StructThe struct containing the variable to move.
MoveVarGuidThe guid of the variable being moved.
RelativeToGuidThe guid of the variable above/below which MoveVarGuid is being moved.

返回
Whether the variable was actually moved.
