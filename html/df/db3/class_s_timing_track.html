void STimingTrack::OnArrangeChildren ( const FGeometry & AllottedGeometry,
FArrangedChildren & ArrangedChildren ) const

Panels arrange their children in a space described by the AllottedGeometry parameter. The results of the arrangement should be returned by appending a FArrangedWidget pair for every child widget. See StackPanel for an example

参数
AllottedGeometryThe geometry allotted for this widget by its parent.
ArrangedChildrenThe array to which to add the WidgetGeometries that represent the arranged children.
