71 Edge Record Definition
72
73 An edge is defined by a pair of edge records, or arcs, allocated in
74 array E of a graph. An edge record represents the edge in the
75 adjacency list of each vertex to which the edge is incident.
76

79
80 v: The vertex neighbor of the vertex whose adjacency list contains

128/********************************************************************
129 Vertex Record Definition
130
131 This record definition provides the data members needed for the
132 core structural information for both vertices and virtual vertices.
133 Vertices are also equipped with additional information provided by
134 the vertexInfo structure.
135
136 The vertices of a graph are stored in the first N locations of array V.
137 Virtual vertices are secondary vertices used to help represent the
138 main vertices in substructural components of a graph (e.g. biconnected
139 components).
140
141 link[2]: the first and last edge records (arcs) in the adjacency list
142 of the vertex.
143
144 index: In vertices, stores either the depth first index of a vertex or
145 the original array index of the vertex if the vertices of the
146 graph are sorted by DFI.
147 In virtual vertices, the index may be used to indicate the vertex
148 that the virtual vertex represents, unless an algorithm has some
149 other way of making the association (for example, the planarity
150 algorithms rely on biconnected components and therefore place
151 virtual vertices of a vertex at positions corresponding to the
152 DFS children of the vertex).
153
154 flags: Bits 0-15 reserved for library; bits 16 and higher for apps
155 Bit 0: visited, for vertices and virtual vertices
156 Use in lieu of TYPE_VERTEX_VISITED in K4 algorithm
157 Bit 1: Obstruction type VERTEX_TYPE_SET (versus not set, i.e. VERTEX_TYPE_UNKNOWN)
158 Bit 2: Obstruction type qualifier RYW (set) versus RXW (clear)
159 Bit 3: Obstruction type qualifier high (set) versus low (clear)
160 ********************************************************************/
161
162typedef struct
163{
164 int link[2];
165 int index;
166 unsigned flags;
167} vertexRec;
168
169typedef vertexRec * vertexRecP;

236/********************************************************************
237 Graph structure definition
238 V : Array of vertex records (allocated size N + NV)
239 VI: Array of additional vertexInfo structures (allocated size N)
240 N : Number of primary vertices (the "order" of the graph)
241 NV: Number of virtual vertices (currently always equal to N)
242
243 E : Array of edge records (edge records come in pairs and represent half edges, or arcs)
244 M: Number of edges (the "size" of the graph)
245 arcCapacity: the maximum number of edge records allowed in E (the size of E)
246 edgeHoles: free locations in E where edges have been deleted
247
248 theStack: Used by various graph routines needing a stack
249 internalFlags: Additional state information about the graph
250
251 extensions: a list of extension data structures
252 functions: a table of function pointers that can be overloaded to provide
253 extension behaviors to the graph
254*/
255

257{
258 vertexRecP V;
259
260 int N, NV;
261
262 edgeRecP E;
263 int M, arcCapacity;
264 stackP edgeHoles;
265
266 stackP theStack;
267
268 graphExtensionP extensions;
269 graphFunctionTable functions;
270};
