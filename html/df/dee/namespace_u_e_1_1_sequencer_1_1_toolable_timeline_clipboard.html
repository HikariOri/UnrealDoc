const FSequencer & InSequencer )

Builds a cache-driven clipboard from the timeline's current clipboard source keys.

Selected keys are copied when present. Otherwise, keys are copied from the scrub head frame in the current cached channel set.

参数
InTimelineTimeline providing the source keys and channel cache.
InSequencerSequencer used to supply clipboard timing environment data.
返回
A populated clipboard, or nullptr if there were no copyable keys.

bool UE::Sequencer::ToolableTimelineClipboard::HasAnyKeysForClipboardOperation ( const ToolableTimeline::FToolableTimeline & InTimeline)

Checks whether the current toolable timeline clipboard source set contains any keys. If the timeline has selected keys, this checks that selection. Otherwise, it checks whether the current cached channel set contains any keys on the scrub head frame.

参数
InTimelineTimeline whose current clipboard source set should be inspected.
返回
True if a copy/cut/delete operation would have any keys to operate on.

◆ PasteClipboardIntoCachedChannels()

FSequencer & InSequencer,

Pastes a toolable timeline clipboard back into the current cached channels. Clipboard entries are matched back to cached channels by identifier, then pasted through each matching key area. Any newly pasted keys are reselected in the timeline on success.

参数
InTimelineTimeline providing the destination cached channels and key selection.
InSequencerSequencer used to supply paste timing environment data.
InClipboardClipboard payload to paste.
返回
True if any clipboard entry pasted successfully.
