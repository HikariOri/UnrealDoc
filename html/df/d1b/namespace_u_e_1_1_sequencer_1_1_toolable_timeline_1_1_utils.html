FString UE::Sequencer::ToolableTimeline::Utils::TickFrameToString ( const ISequencer & InSequencer,
const FFrameNumber & InFrame,
const bool bInRemoveLeadingZeros,
const bool bInUnsigned )

Converts a sequencer tick frame number to its string representation based on the provided formatting options.

参数
InSequencerThe sequencer instance providing context for numeric type interface and settings.
InFrameThe frame number to be converted to a string.
bInRemoveLeadingZerosIf true, leading zeros will be removed from the resulting string.
bInUnsignedIf true, the resulting string will be treated as an unsigned value (no negative sign).
返回
A string representation of the frame number, formatted according to the specified options. Returns an empty string if the numeric type interface is invalid.
