◆ IsDataReady()

bool FSkeletalMeshLODRenderData::IsDataReady ( ) const
inline
返回
Returns true if data is not being streamed/serialized in and is ready for use. If data is being serialized i.e. in midst of Serialize(...) where data is being loaded in, especially from a different thread, this will return false. This is an atomic load and may not be suitable for perf-critical paths.
