15/*
16 A single IMediaPlayerLifecycleManagerDelegate can be registered with the MediaModule to monitor and control
17 player lifecycles throughout the media framework.
18 One possible use case motivating the implementation is to control player creation as system resources are being
19 monitored. As this task is highly dependent on knowledge the media framework itself often does not have, only
20 an application-supplied delegate can be expected to make reasonably good decisions.
21
22 The delegate will receive notifications about major lifecycle events of all players handled by the framework.
23
24 To identify the instances the implementation should not rely on pointer comparisons (the pointers in question
25 may be used in reallocations or may be no longer valid for some notifications), but should rather use the
26 supplied 64-bit ID, which is uniquely (enough) generated for each created instance.
27
28 Notes:
29
30 - All notification callbacks are issued on the game thread
31 - Calls into the system can cause further callbacks to be issued even while the call is ongoing
32 - IControl is the interface allowing access to player data and instance as well as submitting OpenRequests as needed
33 - IOpenRequest is passed into the OnMediaPlayerOpen() callback when a new player is about to be opened / created
34 It contains all information available about the request so that the code can decided to let the request through, delay or deny it.
35 - To just let it pass through return false from the callback
36 - To delay or deny it return true
37 - Keep a reference to the IControl passed in until you are ready to submit the open request or have decided to deny it
38 - To deny it simply do not submit the request and release all references (this will appear to the rest if the system as a failure to open the player)
39 - An InstanceID is available on all callbacks, but be aware that the ID is not yet assigned to an actual player during OnMediaPlayerOpen
40 - The OnMediaPlayerOpen can be called for a certain InstanceID more then once if the player is reused without being destroyed first
41 - This can lead to the need to track >1 resource use cases for a single ID (e.g. some players will only release the last set of resources once the new resources are already allocated for a while to avoid stalls)
42 - Some callbacks may be issued at a time that the player facade associated with the player (and may be even the low level player) do no longer exist. Be prepared for e.g. GetFacade() to return a null reference
43
44 OnMediaPlayerOpen
45
46 Called when a player is about to be opened. If this is the first time the facade receives an open call or if the player type changed this is called before the actual creation of the player.
47 In any case this is called early enough to still stop the open from proceeding. Aside of tracking player activity, the ability to control the processing of open calls is the main purpose of this callback.
48
49 OnMediaPlayerCreated
50
51 Called when the creation of a new player succeeded. Note that the open may still fail if the player later on has issues playing the content it is pointed to.
52
53 OnMediaPlayerCreateFailed
54
55 Creation of the player failed. This will posisbly be called from within the SubmitOpenRequest() call of the IControl interface. It signifies that either the player factory did not manage to create a player
56 or that the low level player failed to open in the synchronous part of its opening process.
57
58 OnMediaPlayerClosed
59
60 The low level player closed the current playback session.
61
62 OnMediaPlayerDestroyed
63
64 The low level player instance just got destroyed.
65
66 OnMediaPlayerResourcesReleased
67
68 The low level player instance release resources. This callback receives a bitmask of possible resource types (Resource_Flag...) to allow proper tracking of players that release certain types of resources at different times.
69 Some players will issue this callback asynchronously, it may hence be triggered long (100-200ms are possible) after the closing or destruction of a player.
70
71*/
