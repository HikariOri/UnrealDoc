bool FAssetRegistryLoadOptions::bMountPointsRequireSeparateAllocationBlocks = false

If true, AssetDatas, AssetPackageDatas and DependsNodes will be individually allocated rather than allocated in a single block, so that they can be individually freed when their mountpoint is unloaded.

TFunction<bool(FName PackageName)> FAssetRegistryLoadOptions::ShouldKeepPackage

If non-empty, called on every FAssetData, AssetPackageData, and FDependsNode loaded from disk, keeping them only if ShouldKeepPackage returns true on their packagename.

◆ Store

FixedTagPrivate::FWeakStorePtr FAssetRegistryLoadOptions::Store

Optional pointer to the FStore previously created by Load, in cases where the same AssetRegistry.bin file is being reloaded. Caution: If this Store is not identical to the one that would be loaded from disk, chaotic crashes can occur during loading or afterwards during reading of AsssetDatas. If non-null, this FStore will be used for all TagData lookups and the serialization of the bytes for it on disk will be skipped.
