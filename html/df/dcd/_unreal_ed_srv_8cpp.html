◆ CreateBoundingBoxBuilderBrush()

void CreateBoundingBoxBuilderBrush ( UWorld * InWorld,
const TArray< FPoly * > SelectedPolys,
bool bSnapVertsToGrid )

Creates an axis aligned bounding box based on the bounds of SelectedPolys. This bounding box is then copied into the builder brush. This function is a set up function that the blocking volume creation execs will call before doing anything fancy.

参数
InWorldThe world in which the builder brush needs to be created
SelectedPolysThe list of selected FPolys to create the bounding box from.
bSnapVertsToGridShould the brush verts snap to grid

◆ CreateHugeTrianglePolygonOnPlane()

FPoly * CreateHugeTrianglePolygonOnPlane ( const FPlane * InPlane)

Take a plane and creates a gigantic triangle polygon that lies along it. The blocking volume creation routines call this when they are cutting geometry and need to create capping polygons.

This polygon is so huge that it doesn't matter where the vertices actually land.

参数
InPlaneThe plane to lay the polygon on
返回
An FPoly representing the giant triangle we created (NULL if there was a problem)
